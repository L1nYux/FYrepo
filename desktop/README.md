# 科研工作台：Windows 桌面本地预览

当前是可以打开窗口操作的本地原型，尚未连接团队服务器，也没有制作独立安装包。

## 打开

在这台电脑上双击桌面的“科研工作台”快捷方式，或者从 Windows 开始菜单打开“科研工作台”。快捷方式直接启动桌面程序，不经过终端。`launch.cmd` 仍可作为备用入口。第一次启动会从现有网页预览复制数据库和附件；以后沿用这个独立副本。当前使用真正的账户登录，已取消自动管理员登录。

快捷方式、应用窗口与桌面界面使用团队提供的 logo，原图保存在 `assets/team-logo.png`，Windows 圆角多尺寸图标为 `assets/team-logo-rounded.ico`（四角透明，保留原始标志）。更换原图后可运行 `build-icon.ps1` 转换图标格式，再运行 `install-shortcuts.ps1` 更新快捷方式。迁移源代码目录后，可运行 `powershell -NoProfile -ExecutionPolicy Bypass -File install-shortcuts.ps1` 更新桌面和开始菜单快捷方式。当前快捷方式依赖本机的源码与运行环境，独立安装包留待后续制作。

本机数据位置为工作目录下 `work/desktop-preview`，连接配置在 `connections.json`，数据库和附件在 `server/`。关闭应用会关闭它启动的本地 Python 服务。桌面端修改不写回原网页预览或线上服务器。

## 功能

- **登录与退出**：未登录时显示桌面登录界面，不展示工作区和账户菜单。填写账户名与密码即可登录，权限按现有账户自动识别；邀请码注册使用原有一次性、可过期和可撤销的邀请规则。左下角头像菜单的「退出登录」注销会话并回登录界面，窗口保持打开；「退出应用」单独关闭程序。退出会清空页面、导航历史、未读数和当前 AI 页面，并停止账户的在线心跳。
- **工作台**：复用网页现有项目、任务、实验、比赛、财务、公告和账户管理。
- **聊天**：复用工作台的公共聊天、私聊、附件和业务引用功能。右键消息可复制、撤回本人消息或从本人记录删除；撤回对会话双方生效，删除只影响自己的视图。删除后消息消失；撤回后气泡消失，在原位置的聊天背景上显示一行轻提示。本人撤回的提示旁有「重新编辑」，不设置倒计时，刷新或切换会话后仍可使用（最近 200 条记录内）。带回文字、可用引用与原附件，修改后发送新消息。发送使用局部更新，空内容禁用发送，发送期间防止重复提交，失败保留草稿。撤回内容不再提供给助手，原附件链接不可继续下载。这里的数据仅限本地副本，其他团队成员看不到。
- **本地仓库**：文件树浏览、文件名与内容搜索、新建文本或源码、直接编辑和 Ctrl+S 保存。图片可预览；Word、Excel、PDF 等文档用本机软件打开。改动列表、文本差异与版本记录供需要时查看；点击同步后先确认改动，再提交到远程仓库。
- **AI 助手**：顶部进入，左侧为独立对话导航，可新建、搜索、切换、重命名或删除自己的对话；侧栏可收起。选择管理员配置的公共池厂商与模型，可以引用工作台资料，按当前账户权限查找、总结、起草。所有助手调用与脚本 API 调用共用团队额度和成员计量。
- **设置**：左下角头像进入账户资料、公开资料、密码与安全、能力模块和本机信息。管理员另有 API 池管理、成员、邀请码、联系方式与回收站。上游密钥改为服务端统一保管，不再配置个人直连。

桌面布局统一使用顶部区域切换、左侧内容导航和右侧工作区。顶栏只有工作台、消息、仓库和 AI 助手，切回工作台与消息会恢复上次浏览位置。登录后的账户头像固定在所有区域的左下角，菜单提供设置、退出登录和退出应用。账户、API 池与团队管理功能统一放在设置侧栏，嵌入业务页面不再出现第二列设置分类。工作台侧栏分别提供公告栏、项目管理、比赛、实验库和财务服务，项目与比赛页面不再重复显示切换标签。API 池只在设置中提供一个管理入口，内部固定使用「连接与模型 / 额度与用量」两个标签；助手不再提供另一个池设置入口。个人用量从头像的「查看用量详情」打开，不混入管理标签，也不显示项目侧栏。桌面工作区不显示公开网站入口；任务详情面板的开关放在桌面顶栏右侧。

若沿用旧的自动登录预览，且本地数据库只有自动创建的 `local-admin`，第一次升级会显示「设置本地登录密码」。自行设置密码后直接进入；这只修改本地预览账户的密码，保留账户 ID、权限、项目及所有业务记录，不修改原网页或服务器账户。确认后生成 `server/.desktop-auth-ready`，以后使用正常登录，不再出现初始化入口。完全空的本地副本也在此步骤创建管理员；已有其他账户的副本直接使用原账户登录。初始化与认证接口只允许持有本次运行凭据的桌面主进程调用，不向业务网页提供免密入口。

新版本 AI 对话按账户保存在业务数据库中，刷新、切换区域和重新打开应用后可继续。历史列表显示最近 100 个对话，按标题搜索可查更早的对话；每个对话展示最近 100 轮，续聊只发送最近部分上下文。历史仅本人可访问，管理员也不能通过对话接口查看其他成员的历史。删除会清除该对话内容，保留实际用量账目；执行中的对话需先停止并完成结算。升级前未关联对话的旧临时结果仍按七天清理，无法恢复当时没有保存的问题正文。发送时，对话及按账户权限读取的相关资料发往公共池中选择的厂商。助手可查任务、项目、实验、公告与本人可见的聊天，也可提取附件正文；不读取本机任意路径或 Git 工作目录，不调用终端，不直接更改业务记录。

## 仓库的简单用法

顶部打开「仓库」后，从左侧文件树选择文件，直接编辑，按 Ctrl+S 或点击「保存」。搜索框可切换文件名和内容，内容搜索可跳到对应行。文件树的 ＋ 可以新建文本或源码文件。文档和图片可以点击「用本机软件打开」；外部编辑完成后重新打开文件查看。编辑器支持 UTF-8 与带 BOM 的 UTF-16LE，保留原有换行和 BOM；其他编码与超过 2MB 的文件用外部软件处理。

日常只显示「保存」和「同步」，「⋯」中可以拉取更新、仅保存本地版本、查看最近 30 次版本记录、刷新列表或打开文件管理器。「同步」会提交当前仓库的全部可见改动，并获取、合并远程当前分支后上传；确认窗口显示文件列表，可选填写修改说明。关闭远程同步后仍可编辑文件和保存本地版本。仓库沿用本机 Git 的认证，首次没有 Git 身份时填写姓名和邮箱一次即可。

切换文件、离开仓库或关闭应用时，未保存的内容会提示保存、不保存或取消。发现文件已被其他软件修改时不会覆盖；请先保留编辑文字，再重新打开文件。合并产生冲突时，改动列表会标注冲突文件；修正文本中的冲突后点击「保存并标记已解决」，再重新同步。复杂冲突及二进制冲突仍由 Git 工具处理。同步不会强制推送，也不会自动部署服务器；选择文件和编辑时不自动访问远程。

在左下角头像 → 设置 → 能力模块，可关闭仓库和 AI 助手，顶部对应入口会隐藏。各人的模块选择与所选仓库目录保存在本机；任务和实验的文字、附件提交不依赖 Git。当前未自动关联仓库文件与业务成果。此轮开发未执行实际提交或推送。

## 简化后的日常操作

- 新建项目、任务和比赛，先填名称即可保存；负责人有默认值，成员、截止日期和说明在「补充信息」中选填。
- 任务成果可以只写一句话，或者只上传文件。默认提交后，子任务自主结项，母任务进入待审核；只想保存阶段成果时，在更多选项取消结项勾选。按钮显示实际动作。
- 实验记录先提供文件上传和自由文字。Word、Excel、PDF、图片或源码可以直接成为记录，无需重新拆填目的、过程和结果；名称与编号自动生成。旧记录已有的详细字段仍可查看和修改。
- 任务提交中可选「同时存入实验库」，同一份文字与文件直接建立实验记录，自动关联任务和项目。
- 记账和报销只突出类型、金额、事由与凭证；日期默认今天。填写出错时保留已填写的报销金额和事由，文件需重新选择。
- 主模块使用顶栏和侧栏切换，顶栏不显示通用返回按钮。任务详情通过项目、上级任务的位置链接跳转；其他详情和编辑页面保留自己的上一级链接。设置侧栏标题旁的 × 关闭设置并直接回工作台首页。项目与任务的红色删除按钮直接显示，有管理权限时可以使用，删除后可在回收站恢复。
- 消息入口显示红色未读数量；实际打开会话、聚焦窗口并看到底部消息后才标记已读。成员私聊列表和成员管理页显示在线状态。

在线状态约每 10–12 秒更新，超过 90 秒没有前台心跳会显示离线。数据库只保存每个账号最新一次心跳，不累积网站运行或用户操作历史。当前仍是独立本地副本，团队成员不会因此连接到这台电脑。

## 架构

采用 Electron 桌面窗口 + Django 本地服务 + 分开的能力模块。业务页面放在 `WebContentsView`，使用现有网页代码；桌面导航、Git 和 AI 界面放在独立的本地页面。网页没有 Node.js 权限，只有随应用提供的桌面界面能通过预加载桥调用指定功能。

- `main.cjs`：窗口、本地服务生命周期、Git/API 调用和加密配置。
- `repository.cjs`：仓库路径限制、文件读写、搜索、版本提交和远程同步；`ui/repository.js` 为文件工作区界面。
- `preload.cjs`：固定 IPC 接口。
- `ui/`：桌面导航、仓库、AI 和连接设置界面。
- `ui/account.*`：所有区域共用的左下角账户菜单。
- `business.css`：嵌入业务页面的桌面布局调整，不改变浏览器版的布局。
- `server.py`：本地数据库副本、迁移和回环地址服务。
- `desktop_auth.py`：桌面登录、一次性本地密码设置、邀请码注册和会话注销；使用现有 Django 认证。

模块目前通过固定接口接入，尚不支持下载安装第三方插件。没有引入完整的智能体运行框架。借鉴了 DeepSeek Harness 的 Electron + 本地服务分工，以及 Codex 的工作区/聊天/设置导航方式。

架构参考：[DeepSeek Harness 架构文档](https://deepseek-harness.github.io/deepseek-harness/reference/)、[Electron WebContentsView](https://www.electronjs.org/docs/latest/api/web-contents-view)、[Electron 安全存储](https://www.electronjs.org/docs/latest/api/safe-storage)。这里是对现有工作台的独立实现，没有复制它们的产品源码或界面资产。

## 开发与后续连接

需要 Windows、Node.js/npm、Git，以及安装了项目 `requirements.txt` 的 Python。当前环境自动寻找相邻的 `../venv/Scripts/python.exe`，也支持设置 `WORKBENCH_PYTHON` 指向其他 Python。进入 `desktop` 后执行 `npm ci` 安装锁定版本，运行 `npm start` 或 `launch.cmd` 启动。

可设置 `WORKBENCH_DESKTOP_STATE` 指定数据目录，`WORKBENCH_DESKTOP_SOURCE_DATA` 指定首次复制来源。迁移发生在独立数据库内，不改原数据库。

下一步接服务器时，应增加远程模式和服务器连接：业务内容、API 池与费用计量共用线上数据库，上游密钥由服务器保管，本地 Git 与能力开关留在电脑上。本地密码初始化仅用于这份旧预览升级或空副本，不用于远程服务器。当前没有数据双向同步、离线冲突处理、后台自动更新或安装包。

本地服务启动失败时可查看数据目录中的 `startup.log`；它仅保存服务错误信息，不记录用户操作审计。

### 桌面回归检查

在仓库根目录执行以下命令。9 个用例覆盖账户/安全设置页签、助手启动期间的重复提交，以及失效请求的恢复处理；使用模拟页面和请求，不调用真实模型。

```powershell
$env:ELECTRON_RUN_AS_NODE = '1'
try {
    & .\desktop\node_modules\electron\dist\electron.exe --test desktop/tests/navigation.test.cjs desktop/tests/assistant.test.cjs
} finally {
    Remove-Item Env:\ELECTRON_RUN_AS_NODE -ErrorAction SilentlyContinue
}
```
