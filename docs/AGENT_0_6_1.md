# 知域授权 Agent 与内置插件

日期：2026-10-10。本轮为源码实现，尚未覆盖安装或部署。

## 已实现的执行链

助手页头 → 工具与执行授权 → 插件启停、项目与操作范围 → 原生模型工具调用 → 服务端授权检查 → 共享业务命令 → 数据库操作与回执 → 对话中展示实际结果。

### 工具注册

`aihub/tool_registry.py` 集中登记受信任工具。注册时拒绝重复工具名、重复插件标识和未知读写类别。工具声明参数、显示名称、处理器和所属插件。模型请求仅选择已登记工具，不能注册代码或指定 Python 处理器。

内置插件：工作资料、互联网资料、任务协作、文档草稿。账户可以关闭插件。模型只收到当前已启用且本轮可用的工具；执行时再次检查开关。安装外部包、MCP 服务、脚本执行和第三方 UI 插件尚未接入，不将内置注册机制称为完整插件市场。

### 授权

`AgentGrant` 绑定当前用户、单个项目、允许工具、1–8 小时有效期以及 1–30 次写入上限。创建授权时验证现有业务权利，执行时再次检查账户、团队、项目和对象权限。资金来源与操作项目分别处理：API 池支付不赋予其他团队项目的操作权。

没有选中授权的对话仅查询和起草。选中授权后，允许的常规操作连续执行。用户通过同一个入口撤销授权；关联运行任务收到停止标志，之后不会开始新的工具操作。已经发出的上游请求仍需完成原有用量结算。

### 第一批写入工具

| 工具 | 校验与结果 |
| --- | --- |
| 创建任务 | 复用 `TaskForm` 和共享命令；成员必须为项目参与者；返回任务详情链接 |
| 更新任务进度 | 当前业务权限、未归档、进行中、0–99；比较读到的进度，冲突时拒绝覆盖 |
| 保存文档草稿 | 项目关联的在线文档、本人可编辑修改稿；比较稿件编号与 generation；正式版本保留审核流程 |

`core/workspace_commands.py` 被现有任务表单、进度接口和文档保存接口共同使用。Agent 不直接修改业务表，不将模型正文或网页内容解析为命令。文档文字转为经过校验的编辑器节点，HTML 不被解释执行。

## 回执、重试与取消

`AssistantJob.operation_group` 表示同一工作及其显式重试。历史任务迁移后分别获得标识，新任务默认独立标识。`AgentOperation` 用操作组和规范 JSON 参数哈希建立唯一约束。

本地业务写入、回执、授权次数扣减位于同一个数据库事务。失败全部回滚。相同参数的成功操作在本轮或其重试中复用回执，不再次创建任务、保存草稿或消耗授权次数。复用前仍检查当前权利。不同独立任务可有相同操作参数。

执行和撤销使用相同的授权→任务锁顺序。SQLite 在读取前先取得写锁，减少并发读写升级冲突。取消、插件关闭、授权过期或成员退出均在后续工具调用时生效。

参数发生变化意味着新操作；这不是语义级重复识别。对话中的费用、失败和成功回执分别显示，不用模型的“已完成”文字替代回执。工具过程展示实际对象链接，重复操作标为“复用已提交回执”。

## 检查与界面

- 166 项 Django 检查通过：授权缺失、过期、撤销、账户停用、成员退出、跨项目、插件关闭、取消、次数上限、同参数重试、事务回滚、进度冲突和文档版本冲突，以及现有助手与协作流程。
- 26 项共享请求运行时检查通过；修改脚本语法检查通过；`makemigrations --check --dry-run` 无缺失迁移。
- 30 项浏览器和集成检查通过，覆盖 320、390、1280 像素页面、插件启停、授权提交、长项目名省略、真实任务写入、服务端回执、实际详情链接和撤销后恢复查询模式。未捕获异常及失败业务请求均为 0。
- 同一新账户的 6 个真实 SQLite 线程并发初始化额度，复用同一记录。首次初始化先取得写锁；读取已有额度不产生写入，不重置余额或开关。

浏览器使用真实 Django 页面和 Android 资源，原生强调色协议由检查夹具模拟。模型上游回复为确定性工具调用，实际授权、业务命令和数据库回执照常执行；没有发生真实供应商付费推理。它不能代替真机和安装包验收。

日志、截图与检查脚本位于工作区 `outputs/agent-0.6.1/`，运行脚本为 `outputs/review-agent-ui.py`。
