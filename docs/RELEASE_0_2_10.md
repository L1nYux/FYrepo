# 科研工作台 0.2.10

- 浅色聊天侧栏和账户区使用白色；红包领取、转账接收后卡片变暗，每次领取产生可查看详情的会话提示。点数显示最多一位小数，转赠仍仅使用额外点数。
- 聊天气泡右键或长按引用，发送成功清空引用，失败保留；点击头像查看公开成员资料。新增表情面板、图片/GIF 表情收藏、上传与移除。
- 头像上传增加移动、缩放、旋转和触控裁剪，确认后才替换图片。
- 实验可先按名称创建，分别管理设计、运行、文件、结果；准备中的实验可关联 API Key。运行接口可创建记录，再按 run_id 补结果；原有数据保留。
- AI 助手增加公开互联网搜索、网页/PDF 正文读取，显示搜索与阅读状态及可点击来源。桌面右侧内置独立浏览器支持返回、刷新、收起和外部打开；网页端提供正文预览。
- 本地支持打开多个仓库/文件夹、切换、关闭和确认后移入回收站；未选仓库也能选择保存位置创建文件。切换前处理未保存草稿。
- 时间排序增加稳定的主键次序；主要列表分页，实验及调用增加查询索引。新增独立 404/500 页面、无敏感内容的运维邮件、healthz 与按 HTTPS 配置启用的 HSTS。
- Linux、Windows 完整检查成为发布前置条件：370 项 Django、45 项 Node、5 项 SQLite 并发、9 套 Electron 界面检查。修正页面 fixture、旧测试数量和安装说明缺失文件。

服务器需同步升级才会启用新接口、表情和实验迁移，沿用原账户、附件、SMTP 和 API Key。客户端仍使用 0.2.9 接通的正式 Release 更新通道。免费 Mac 会检查和下载，并在确认后打开 DMG，仍需拖动覆盖安装。

联网读取只支持公开网页；需要登录、仅 JavaScript 渲染或扫描 PDF 的页面会说明未读到正文。公共搜索服务可能被限流。服务器保留公开 DNS、证书及逐次跳转检查；内置浏览器独立于账户会话，没有本机文件或工作台管理权限。没有执行真实付费 AI 调用；未在本机验证 Mac 安装运行，生产升级由负责人执行保留数据脚本。
