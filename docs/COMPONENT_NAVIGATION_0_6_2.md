# 项目、任务列表组件导航

2026-10-11。第一批范围为 `/projects/` 与 `/tasks/` 的列表切换、搜索、状态/类型/成员筛选、归属切换和翻页。

同一 `work-list` 组件保持标题、筛选表单和分页入口，只更新列表数据。请求沿用原页面地址，携带 `X-Zhiyu-Component: work-list-v1`；服务端与首屏 HTML 使用同一数据契约、权限查询和进度计算。普通访问仍由服务端渲染，关闭 JavaScript 也能浏览列表、筛选和打开记录。

组件不缓存业务数据到磁盘。页面内 GET 合并按账户、归属、完整 URL 和请求头变体隔离；每次完成读取后过期。历史返回保留筛选与滚动位置，重新读取当前权限下的数据。新搜索取消旧订阅，迟到响应不覆盖当前列表；写入会使查询代次失效。

加载失败、登录失效和权限撤销清掉之前的记录，再显示错误及重新读取。重新读取只进行 GET；业务写入继续使用原有表单和事务命令，不经列表导航隐式提交。

项目进度只汇总当前页可见项目的任务；任务母项进度使用批量平均值，负责人资料通过关联查询读取。外部协作授权加入“与我有关”的数据库筛选，避免在分页后过滤造成漏项和错误计数。

本批 52 项列表、前端依赖、工作区与转发回归通过。28 项共享 Runtime 测试通过。浏览器覆盖 1280、390、320 像素，验证组件与表单对象不变、没有额外文档请求、搜索、后退、归属、失败重试与权限撤销。详细断言和截图见 `outputs/component-navigation-0.6.1`。

这是已迁移的两个列表模块。项目/任务详情和写入表单、文档、实验、财务等模块尚未完成同一导航改造；不能把本批描述为全站单页应用。
