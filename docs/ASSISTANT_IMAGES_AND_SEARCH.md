# 图片输入与公共搜索

## 图片

AI 助手支持粘贴截图、选择图片和拖放图片。每条消息最多 4 张，每张原图最多 8 MB。服务端按实际文件内容解码，移除元信息，缩小到最长边 1536 px，转换为 JPEG；GIF 取首帧。

上传和发送是两步。上传不调用模型、不扣 AI 点数。发送前浏览器和服务端都会检查识图能力。不支持时返回 `image_not_supported`，保留图片和文字，要求用户切换模型；没有创建助手任务、调用或额度预留。带图历史和重试也执行同一检查。

厂商目录明确声明图片输入时优先使用声明。已核实的 MiniMax M3、千问视觉系列和部分 GLM-V 型号自动识别。陌生型号默认不启用；API 池高级模型设置中可以将“支持图片输入”设为是或否，留空使用自动识别。模型列表中识图型号标注“识图”。管理员应按厂商文档填写，程序不会通过付费请求探测能力。

图片只通过本人登录后的受保护地址展示，不生成公开媒体链接。会话记录保存图片关联，删除会话或自动清理历史时删除不再被其他会话引用的图片。待发送图片可移除；超过一天的孤立草稿在下次上传时清理。

发送给厂商时分别转换为 OpenAI `image_url`、Anthropic `image/source/base64` 或 Gemini `inlineData`。图片有独立输入额度预留，最终点数按上游实际 usage 结算；不把 Base64 文本长度当成实际 token 数。

## 搜索

默认依次尝试必应国内 RSS、必应国内网页、百度网页和 DuckDuckGo；只接受真实返回的相关来源。保留 DNS 公网检查、地址固定、TLS 校验和跳转重新校验，支持多个公网地址、有限压缩解码和页面字符集。遇到验证页、不相关结果或网络故障时提示未完成，不编造网页数量。

搜索成功后尝试读取前两个来源正文，呈现真实搜索/阅读步骤、来源编号和右侧结果面板；某页拒绝读取时保留搜索摘要并明确提示读取失败。

免费公共搜索网页会受地域网络、验证码和页面结构影响，不能保证永久可用。可用 `WORKBENCH_SEARCH_URL` 指定自己的公开搜索服务，支持 RSS、受支持 HTML 和 SearXNG 风格 JSON（含 `results[].url/title/content`）；地址须是可访问的公网 HTTP/HTTPS 地址。

在服务器当前版本目录，用运行服务的环境执行：

```text
.venv/bin/python manage.py diagnose_web_search --query "benchmark 机器学习"
```

此命令输出各来源的连接时间、响应类型、解析数量或具体错误，不调用 AI、SMTP，也不打印厂商密钥。应从实际部署服务器执行；开发电脑的代理、DNS 及连通结果不能代替服务器诊断。
