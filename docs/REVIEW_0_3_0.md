2026-10-06，Windows 本地开发分支候选版；尚未合并或部署 Production。

## 已完成检查

- Django 572 项全部通过，实际 Chromium 网页读取用例已启用；没有跳过这三项。
- Node 54 项全部通过。
- 全部 14 套 Electron 页面检查通过；其中新个人聊天检查覆盖图片粘贴、发送失败保留草稿、刷新恢复文字、头像/气泡显示、引用、撤回重编、历史查询、免打扰、清空与普通好友群资料。
- SQLite 5 项积分并发检查通过：重复发送、并发领取、重复领取、并发过期退款、红包与 API 额度预留竞争。
- 同时接受好友请求只生成一条关系；竞争交接团队所有权只有一个成功；最后一个成员名额只分配给一人。
- 填充 0.2.17 与 0.2.20 结构的临时旧库升级通过：账号、密码、邮箱、成员资格、记录主键、余额、私聊/群历史、引用、隐藏/已读偏好保留；再次运行迁移不重复生成记录。
- 五个元老账号兼容迁移检查通过，新管理员和新成员不会获得元老登录别名。
- 本地桌面隔离认证四项检查通过；注册经过邮箱验证码验证。
- 数据库迁移无模型差异；系统检查与 Git 空白检查通过。
- 私聊与好友群浅色/深色截图已检查：消息侧栏浅色为白色，发送按钮在右下角，头像位于气泡外。

## 修复的回归问题

- 同时退还过期红包时，旧维护路径在事务内先解析空间，导致 SQLite 读锁升级失败；现在在事务外解析空间，并先获得写锁。
- 消息动作标记误放在整条消息上，使动作按钮的透明度规则隐藏消息；标记改回动作按钮。
- 软件账号管理权限与团队管理能力的入口没有完全分开；补齐独立入口、受保护账号的操作显示和岗位项目管理按钮。
- 合并旧私聊后，较旧消息的新主键会大于较新个人消息；改为按原时间展示和选取会话预览，历史分页使用消息时间锚点，已读仍使用单调游标。
- GitHub 的 Linux 检查通过；Windows 首轮检查发现经典滚动条挤偏收起侧栏图标。收起时隐藏空间表单，并让滚动保持可用且不挤占图标区域，随后本地复查通过。
- 新客户端连接尚未升级的服务器时，显示原团队但禁用空间切换，管理入口沿用旧路由；切换到新版服务器后恢复个人/团队选择器。兼容界面两项检查通过。
