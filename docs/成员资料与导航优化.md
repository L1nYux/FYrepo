# 成员资料与导航优化

## 使用入口

- 网页工作台导航顶部、桌面工作台导航顶部：展开或收起侧边栏。展开 232 px，收起 68 px；状态在本机保留，悬停图标显示菜单名称。
- 公告栏：独立卡片之间间隔 20 px，内部留白 24 px。
- 账户菜单 / 桌面设置 → 成员资料库：搜索账户名、昵称、公开姓名及公开研究方向，查看负责项目和公开简介。
- 点击成员头像或姓名：打开统一资料卡。未公开的研究方向和简介不会展示。
- 管理员通过成员卡片的“⋯”菜单执行任免、停用、密码重置或账号删除。

## 密码重置

不要求成员绑定邮箱。管理员确认后生成 24 小时有效的随机临时密码，明文只在本次页面显示，可复制后私下交给成员。原密码、原会话和成员 API Key 失效。成员登录后先设置一个与临时密码不同的新密码，再进入工作台。账号停用状态不会因重置密码而改变。

## 删除账号

删除确认页列出未归档项目、任务、比赛以及 API 池负责人身份，存在负责事项时需要选择在用的接任成员。API 池负责人只能交接给管理员，任务交接同时加入任务所属项目。

账号退出成员目录，禁用登录，清除姓名、邮箱、头像及公开资料，撤销成员 API Key、未使用的邀请码和验证码。保留不可登录的历史作者占位记录，不级联删除项目、实验、成果、财务或聊天。旧私聊可查看，不能继续发送消息、红包或转账。当前账号和最后一位在用管理员受到保护。

## 部署

本次包含 core/0023_member_account_lifecycle 数据库迁移。使用已有的数据保留升级流程安装服务器代码，运行数据库迁移并收集静态资源；桌面侧边栏修改需要重新构建并安装桌面包。

这些改动仍使用当前单团队权限模型，不包含多团队扩容。
