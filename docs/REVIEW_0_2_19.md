# 0.2.19 复查与修订

## 发现并修复

| 问题 | 修订与回归证据 |
| --- | --- |
| 团队介绍表单保存完整团队对象，可能覆盖同时调整的人数上限 | 只更新表单的三个字段；模拟并发修改上限并确认保留 |
| 重复投递的唯一约束异常破坏外层事务 | 在独立保存点处理重复投递；返回可读提示，保留原申请 |
| 消息按时间排序但用编号翻页，时钟回退导致漏消息 | 增量查询按编号排序；101 条消息跨页且最后一条时间回退的用例通过 |
| 无效游标先发送消息再返回错误 | 在写入前验证游标；非法请求不产生消息 |
| 中文相邻的 benchmark 拼写错误未纠正，英文主题可被子串或部分关键词替换 | 使用英文词边界与完整关键词保留；修复前两项新增用例失败，修复后通过 |
| 无团队账号被桌面导航拦住个人社区入口 | 开放团队广场与个人聊天；客户端实测仍拒绝团队项目和 AI 入口 |
| 快速切换网页来源，旧响应覆盖新正文 | 每次读取绑定独立请求；故意让被取消的旧请求迟到，正文与地址仍对应新来源 |
| 原生浏览器调用异常未处理 | 显示友好提示和原网页链接；模拟桥接异常无未捕获错误 |
| 子框架加载失败误报整页失败 | 只处理主框架失败；分别模拟子框架与主框架错误并验证刷新恢复 |
| 独立浏览器加载期间收起或销毁，可能产生未处理拒绝 | 处理工具栏加载异常、对象销毁及重复清理；快速打开 / 收起 / 销毁测试通过 |
| 个人聊天发送成功后旧错误提示残留 | 成功发送清除旧提示；在界面套件中验证 |
| 好友接受与团队交接存在 SQLite 读锁升级竞争 | 事务先取得写锁；双向同时接受只建立一个好友关系，两个并发交接只保留一个有效所有者 |

修复前六项新增后端用例得到五个断言失败和一个事务错误；修复后全部通过。

## 本地检查

- Django 522 项，包括开启沙盒的 Chromium 网页读取与当前模板生成。
- Node 52 项；Electron 13 套，包括新的浏览器和无团队导航用例。
- 积分真实并发 5 项；团队最后名额并发 1 项；好友与交接并发 2 项。
- 旧数据库迁移保持、本地桌面账号与团队隔离检查通过。
- 没有新增数据库迁移；`makemigrations --check --dry-run` 无差异。

检查使用隔离数据和模拟模型响应。没有调用付费模型，也没有操作正式服务器数据。Linux / Windows CI 状态以对应提交的 GitHub 检查为准；Mac 构建不等同于 Mac 实机验收。

本轮保留 0.2.19 版本号，在现有开发分支和 PR 中交付修订；未合并、未发布正式自动更新，未部署 Production。服务端修订需通过保留数据的升级流程应用。
