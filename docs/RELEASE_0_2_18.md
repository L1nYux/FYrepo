# 科研工作台 0.2.18

本版提供多团队权限、注册与团队切换，以及实际联网搜索和 Chromium 网页读取。软件管理员与团队管理员分离，私有业务和 AI 数据按团队隔离。

完整功能与限制见 [桌面更新说明](DESKTOP_RELEASE_NOTES.md)，权限和运维细节见 [团队分层与联网读取](TEAM_SCOPES_AND_WEB_READER.md)。

## 安装与服务器升级

Windows 覆盖安装保留原配置；客户端连接的服务器也需要从同一提交执行 `deploy/upgrade_preserve_data.sh --apply`。脚本先备份、检查迁移，再安装浏览器并切换服务。

升级包含 core.0024 与 aihub.0016。旧数据迁入默认团队，账号、密码、附件和 API Key 保留。管理员自行执行服务器升级；桌面升级不会修改服务器。

本版不配置 Preview，开发 PR 不会触发正式服务器部署。公开自动更新发布与合并仍需单独安排。
