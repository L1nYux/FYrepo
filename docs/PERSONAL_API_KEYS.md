# 成员的实验 API Key

入口：头像 → 查看用量详情 → 我的 API Key。

1. 选择关联实验。成员可选自己创建的实验或参与项目下的实验；管理员可选团队有效实验。归档项目下的实验不可调用。
2. 填写用途（可选），生成 Key，复制保存。完整 Key 只在本次生成后显示，数据库保存摘要；重新打开页面不能找回全文，可以撤销并重新生成。
3. 复制 API 地址与模型 ID，在脚本或 OpenAI 兼容软件里配置。关闭流式输出，新 Key 的请求自动关联实验，不需要软件支持额外实验字段。
4. 页面提供随所选模型和实验更新的 Python、curl 示例。Python 使用标准库，运行时输入 Key；复制示例不会自动包含 Key。

一个新 Key 绑定一个实验。更换实验应生成对应 Key；请求若包含 `experiment_id`，必须为正整数且与 Key 一致。旧 Key 没有绑定关系，每次请求必须提供有效的 `experiment_id`，建议改用新 Key。

每次独立调用重新校验成员与实验权限；实验删除、项目归档、成员退出项目或 Key 撤销后，相应调用被拒绝，不发起模型推理或扣积分。实验删除不会让原 Key 变成无限制的通用 Key。实验 API Key 和工作台聊天共用成员积分，日常聊天无需关联实验。

## 接口

基础地址：工作台域名 + `/api/pool/v1`。认证为 `Authorization: Bearer <我的 API Key>`。

- `GET /models`：返回已启用且完成密钥和价格配置的模型。
- `GET /experiments`：返回当前 Key 所属成员可关联的实验（ID、实验编号、名称、项目 ID），支持 `q` 搜索，最多返回 200 条，`has_more` 表示搜索结果是否仍有更多。
- `POST /chat/completions`：非流式文本 Chat Completions。新 Key 自动绑定实验；旧 Key 要求 `experiment_id`。`project_id` 可以省略，由实验确定，显式提供时必须一致。

调用响应的 `workbench` 中返回 `experiment_id`、`experiment_number`、`project_id` 和用量记账信息。调用记录保存成员、模型、实验、项目、费用与积分归属，页面显示实验链接。

## 升级

新增 `aihub.0009_member_key_experiment`，为原有 Key 加入可空实验关联与绑定状态；原有 Key、账户、调用记录和积分不删除。使用保留数据升级脚本，执行迁移并收集静态文件。无需重装桌面版 0.2.7。

## 检查范围

使用隔离数据与模拟厂商响应检查生成、只显示一次、成员隔离、撤销、实验权限、归档、删除、旧 Key 兼容、普通请求自动归属、冲突编号拒绝及积分结算。实际 Electron 页面检查复制成功、剪贴板拒绝后的兼容处理、示例切换、无模型状态、字符转义、手机按钮尺寸与桌面入口；不使用真实密钥或发起付费调用。
