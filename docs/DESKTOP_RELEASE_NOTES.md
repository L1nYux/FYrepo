# 科研工作台 0.2.18

## 多团队与权限

- 可以无邀请码注册，在「我的团队」创建、加入或切换团队。
- 软件管理员与团队所有者、管理员分开；新建团队不获得软件管理权限。
- 项目、实验、消息、附件、API 池、积分、个人 API Key 和 AI 历史按团队隔离。
- 移除成员只改变当前团队资格，保留历史及其他团队资格。共享账号密码由本人找回或软件管理员处理。
- 切换团队或账号会清理旧导航、请求和内置浏览器会话。

## AI 联网搜索与网页读取

- 用户要求搜索或读取网页时，先执行实际工具，再组织回答；兼容现有模型提供商及多轮调用。
- 免费公共搜索支持备用来源，筛选相关结果，并尝试读取前两个来源正文。
- 支持用 Chromium 读取需要 JavaScript 的网页；进度和引用基于实际结果，右侧来源面板可打开内置浏览器。
- 修复 Windows 网页读取卡住的问题，补充 Ubuntu 浏览器沙盒路径许可和启动检查。
- 免费搜索额度、验证码、目标网站限制及服务器网络仍可能影响结果；无法读取时显示失败原因。

## 升级

服务器必须同步升级：包含 core.0024、aihub.0016 迁移及 Playwright/Chromium 安装，保留原账号、项目、API Key、附件和点数。只有桌面安装包升级无法启用上述服务端功能。

Windows 安装包支持覆盖安装并保留原配置。Mac 由 GitHub 构建 Apple Silicon 与 Intel 安装包；免费版本仍需确认后覆盖安装。

本次不配置 Preview，也不代替管理员部署正式服务器。开发说明见 [团队分层与联网读取](TEAM_SCOPES_AND_WEB_READER.md)。
