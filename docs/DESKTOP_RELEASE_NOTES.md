# 科研工作台 0.2.9

- 头像旁新增更新按钮：启动后及每 4 小时检查，自动下载新版本，显示进度与就绪提示，失败可重试。
- Windows 下载完成后确认安装，自动替换并重启。保留账户登录、服务器地址、本地配置和团队数据。
- 免费 Mac 版本自动检查、按 Apple Silicon / Intel 下载并校验安装包；确认后打开 DMG，退出应用并覆盖安装。无需购买 Apple 开发者会员，但不是静默安装。
- 修复 AI 助手打开公告引用后，“消息”导航错误回到公告的问题；恢复之前真正的聊天。
- 聊天侧栏与账户底栏统一深色，去掉顶部多余留白，优化气泡对比、间距与操作按钮。
- 红包、转账、额外点数与用量统一显示最多一位小数，账本精度不变。

## 安装与更新

首次安装从本发布页选择 Windows x64、macOS arm64（Apple Silicon）或 macOS x64（Intel）安装包。
Windows 旧版 0.2.7 / 0.2.8 已有更新检查器，可在“设置 → 关于与更新”获取本版；安装后使用头像旁按钮。
旧的未签名 Mac 版本需要手动覆盖安装本版一次，之后即可在应用内检查和下载。
Windows 与 Mac 安装包未使用付费发行证书，系统可能要求确认开发者。Mac 保持系统安全检查，通过系统提供的允许打开入口确认可信来源，不需要关闭系统安全保护。

网页样式和点数展示需同步升级服务器。应用更新只更新客户端，不会替服务器执行迁移。

# 科研工作台 0.2.8

- 新增头像上传，统一显示在账户、聊天和成员资料；公开头像跟随公开资料授权。
- 聊天列表固定深色，突出当前会话；新增免打扰、历史筛选与定位、个人清空和移除会话。
- 聊天支持额外 AI 点数转账、均分或拼手气红包，24 小时未领取部分退回。每周基础额度和调用预留点数不能转赠。
- AI 回答显示 Markdown，引用以资料卡片呈现，避免将内部地址和工具数据写入普通回答。

服务器需要同步升级到本次代码，启用新的头像、会话和积分接口；原账户、数据、附件、邮箱配置及 API Key 保留。桌面版 0.2.8 增加本地账户角落头像及聊天页配色。详细说明与验证范围见 [0.2.8 更新说明](RELEASE_0_2_8.md)。

## 上一版功能

- 团队资料保存留在工作台；公开页面通过明确的预览入口打开。
- AI 消息发送后清空引用，失败气泡提供重试；断线继续原任务，重试保留新草稿。
- API 池新增厂商额度刷新：MiniMax M Plan 与按量余额、智谱套餐额度；千问和未接入的现金余额提供官方控制台入口。
- 修复验证码按钮提交问题，已登录的邮箱找回页面保留工作台布局，兼容手机屏幕。
- 保留 0.2.5 / 0.2.6 的邮箱或用户名登录、未绑定邮箱提醒、财务回收站与永久删除确认、本地设置及 Logo 加载动画。

桌面版保留原账户登录状态和本地配置。服务器需要同步升级至 0.2.7，才会启用新的消息接口、额度查询和网页修复。使用保留数据升级脚本，原数据库、附件、SMTP 与 API Key 保留。

历史说明：0.2.8 分支产物尚未接通正式发布。0.2.9 起使用上述免费更新流程。

详细说明与验证范围见 [0.2.7 更新说明](RELEASE_0_2_7.md)，部署步骤见 [连接与发布](CONNECT_AND_RELEASE.md)。
