# 知域 0.4.1：导航、权限与用量修复

- 统一个人与团队资源入口，修复项目、任务和子任务标题与展开层级。
- 聊天、通讯录、团队、发现、软件管理各有上下文导航。
- 人才市场默认自愿公开；团队支持公开招聘和定向 offer；主动申请通过直接入队。
- 支持仅参与项目的合作邀请，不附带其他团队权限。
- AI 对话属于本人，个人与团队扣费来源独立选择；撤销资格后重新检查。
- 团队 API 池分发、补发与重置日常免费额度；个人自付用量的点数补发必须附凭证，凭证不包含聊天内容，重复审批只发放一次。
- 标准 emoji 完整分类库含 1,870 种表情，计入肤色变体共 3,395 个选项；支持点选、输入法与复制粘贴。聊天、项目/任务留言及文档评论保存为 Unicode 文字。聊天和普通留言保留自上传图片表情；文档评论本次仅提供标准 emoji。
- 团队邀请、入队和团队群加人需要 HR；只有所有者默认拥有 HR，也只有所有者可授予和撤销。
- 客户端默认 HTTPS 并校验证书；临时远程 HTTP 需要明确确认，许可仅在当前应用进程有效。
- 样本库加入工作台导航与归属筛选；读取、编辑、采集及文件下载检查个人或团队权限，历史样本迁至唯一团队。
- 客户端与服务端版本分别展示，更新弹窗和关闭到托盘。

- 我的 API 集中提供连接、模型与用量，按个人或团队额度查看。
- 普通成员可选择团队创建实验；修正消息切到仓库后的状态和账号底栏。
- 科研文档支持应用内阅读、独立修改稿、审核与固定成果版本；策划书可生成供确认的项目与任务。Word、Excel 在线编辑需要独立文档服务。

服务端与客户端需同步升级。**本次包含数据库迁移，回滚需恢复升级前备份。**当前是本地待发布包，尚未发布自动更新。验收范围见 `RELEASE_0_4_1.md`，服务器步骤见 `SERVER_UPGRADE_0_4_1.md`。
