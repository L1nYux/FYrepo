# 科研工作台 0.2.15

## 修复搜索跑偏与工具协议泄漏

- 用户要求“能帮我查一下什么是brenchmark吗”时，备用搜索提取主题 `brenchmark`，不再把整句请求直接交给搜索服务。不擅自改写拼写；原生搜索工具提示模型选择正确主题词。
- 搜索结果标题、摘要与查询词明显不匹配时，尝试另一个公开来源；两处仍无相关结果则明确失败，不展示字典页面冒充主题资料。词面匹配是粗筛，不代替内容核实，不能保证每条结果都相关或正确。
- MiniMax 官方 OpenAI 接口提供工具的回合改用完整响应，开启独立推理字段，保留完整 assistant message 与 reasoning_details；阶段和最终推理仍显示，提供工具的回合不逐字流式展示。其他厂商继续原有流式行为。补齐 api.minimax.cn 的默认工具能力识别；不改已有管理员设置、不切换 API 地址。
- 正文中的 MiniMax 分隔符、工具 JSON 或调用标签只用于识别异常，不执行。遗漏操作与无效格式分别最多纠正一次，整轮仍最多四次模型调用，要求通过本轮提供的原生工具接口继续；始终保留权限、调用计量、工具去重、时间与次数限制。
- 无效格式重复出现时，消息显示未完成与重试按钮。历史回复及流式过程隐藏泄漏的指令尾部，代码块中的合法示例保留。输出截断、断流和费用未确认不追加付费调用。
