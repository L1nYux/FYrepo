# 科研工作台 0.2.0

- 桌面端可连接团队服务器，使用原有账户和邀请码；网址与保持登录状态在本机保存。
- 官网、网页工作台和桌面共享服务端账户、任务、实验、聊天、财务、AI 历史与 API 用量。
- Windows 安装程序创建桌面与开始菜单快捷方式；macOS 提供 Apple 芯片和 Intel 两种版本。
- 安装版自动检查与下载更新，安装前提醒保存内容，由使用者决定重启。
- 本地 Git、编辑器、能力开关、深浅色与壁纸保留；不把本地预览数据库上传或覆盖服务器。

首次安装：填团队服务器网址，使用原账户登录。服务器必须升级到支持 `/desktop/api/status/` 的版本。包中不包含团队数据或 API Key。

Mac 正式自动更新需要 Apple Developer ID 签名与公证；无证书的分支产物仅作预览。Windows 没有组织签名时可能提示未验证发布者。

上线与签名、保留数据升级步骤见源码 `docs/CONNECT_AND_RELEASE.md`。本版本不支持离线业务写入、自动部署服务器或本地数据库双向同步。
