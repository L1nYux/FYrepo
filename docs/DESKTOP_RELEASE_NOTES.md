# 科研工作台 0.2.7

- 团队资料保存留在工作台；公开页面通过明确的预览入口打开。
- AI 消息发送后清空引用，失败气泡提供重试；断线继续原任务，重试保留新草稿。
- API 池新增厂商额度刷新：MiniMax M Plan 与按量余额、智谱套餐额度；千问和未接入的现金余额提供官方控制台入口。
- 修复验证码按钮提交问题，已登录的邮箱找回页面保留工作台布局，兼容手机屏幕。
- 保留 0.2.5 / 0.2.6 的邮箱或用户名登录、未绑定邮箱提醒、财务回收站与永久删除确认、本地设置及 Logo 加载动画。

桌面版保留原账户登录状态和本地配置。服务器需要同步升级至 0.2.7，才会启用新的消息接口、额度查询和网页修复。使用保留数据升级脚本，原数据库、附件、SMTP 与 API Key 保留。

Windows 安装包未签名。macOS 产物由 GitHub 构建，正式自动更新需要签名与公证。分支构建产物不等同于已发布的自动更新。

详细说明与验证范围见 [0.2.7 更新说明](RELEASE_0_2_7.md)，部署步骤见 [连接与发布](CONNECT_AND_RELEASE.md)。
