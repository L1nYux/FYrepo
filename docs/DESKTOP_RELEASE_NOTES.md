- 招聘管理与退出/解散入口可在手机访问，项目和任务表单可打开，任务进度操作可展开。
- AI 模型选择位于顶部；强调色按账户和设备保存，并在页面导航后恢复。

# 知域 0.6.0：协作流程与团队 API

- 聊天引用新增项目与文档，支持名称、正文和编号搜索；修复私信按当前团队过滤导致搜不到资料。
- 聊天资源引用直接打开对应列表，返回恢复原会话；查看继续校验源资料权限。
- 统一拍摄、相册与工具图标画布和尺寸，保留四列两行的滑动分页。
- 以消息身份合并本机缓存和服务器记录，避免发送后旧卡片重排、重复出现。
- 电脑扫码确认使用专用页面，二维码中心显示知域标志。
- 删除、招聘与项目操作使用应用确认提示，避免显示服务器网址。
- 招聘管理支持取消全部、单条取消、暂停、重新开放和编辑，入口位于团队概览及团队页签。
- 手机项目任务详情与操作放入页面，团队设置明显提供退出、转交和解散。
- 模型默认自动同步公开价格，支持显式自定义与恢复同步，保留历史价格版本。
- 团队 API 新增 OpenAI 兼容 SSE 流式响应与用量结算；连接中断保留待核对预留。
- 增加成员月度额度、重置卡发放与自行兑换，保留额外点数、在途预留及费用历史。
- 长请求维护调用心跳与并发租约，避免被后台清理误判为服务中断。
- AI 助手资料选择改成独立页面，新增文档检索，修复停止响应和页面切换后的状态回写。
- Android 随包组件仅在内容哈希匹配时使用，防止旧客户端资源覆盖服务器新页面。
- 桌面长期复用内容哈希资源，修复表情变更的缓存失效范围。
- 官网改为知域产品介绍、协作与 AI 能力以及下载入口。

## 安装与部署

Windows 客户端已构建并覆盖安装至本机；Android 包使用原签名，可覆盖安装。服务端必须同步升级才能应用数据库、网页和 API 改动。

自动读取价格失败时保留最近有效版本，无价格的模型不会默默按零费用调用。旧自定义价格保留手动模式，可在管理页恢复自动同步。

## 当前边界

- 内部 API 流式接口支持 OpenAI 兼容上游逐段返回；Anthropic 与 Gemini 原生适配暂在生成结束后返回兼容事件。
- Bearer 接口仍以文本、工具调用为主；手机相机、剪贴板、系统下载及真实供应商调用需要设备和账号验收。
- 这次完成源码和模板编译、Windows 与 Android 打包；未运行自动化业务测试，未连接真实供应商执行付费调用。
- 生产服务器现有 SSH 凭据被拒绝，因此本次未修改生产数据库、部署网页或发布自动更新渠道。
