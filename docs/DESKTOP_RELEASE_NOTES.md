# 知域 0.5.2：团队工作台与交互修复

- 原个人空间升级为封闭单人团队，保留项目、任务、文档和历史记录编号。工作台只保留一个归属选择，创建内容继承当前团队。
- 人才、团队联系以及申请和合作进度汇入私信；发现只保留团队广场、人才市场。公告支持按权限确认删除。
- 桌面和手机从原入口优先读取账号隔离的本地缓存，已缓存的项目、任务和聊天可离线浏览；恢复联网后再更新。
- 重排联系人资料、聊天信息和群管理页面；消息列表整行及头像均进入聊天。顶部加号采用附着菜单。
- AI 输入区用一个加号展开图片、拍摄、文字文件和引用，修复模型将工具指令直接作为回答的问题。
- 图片不再显示多余文件名，特殊消息显示类型摘要；群默认聚合成员头像，可由群主或管理员上传群头像。
- 我的积分以两位小数展示，后台精度保留；红包和转账分别提供图标和入口。免打扰、置顶在各入口保持同步。
- 保留已确认的 Windows 任务栏图标修复，托盘显示“进入知域”。保留移除 240 秒总时长限制的热修。

客户端和服务器需要同步升级。服务器脚本先备份数据库、附件和配置，再切换版本；需要回滚时使用备份。

未配置的手机厂商推送不能保证应用被系统终止后送达；后台消息卡片与厂商离线推送是两项能力。Windows 安装包没有商业代码签名。MiniMax 待核对调用不自动重发，也不在没有上游账单证据时扣款或释放预留。
