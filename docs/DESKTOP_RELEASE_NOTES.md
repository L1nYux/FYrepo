# 知域 0.3.1：统一入口与清晰聊天

- 项目、比赛、实验统一显示个人和已加入团队的资源，显示归属，可按归属筛选。
- 打开记录自动检查所属空间的资格与权限，不修改其他页面的空间选择。
- 首页显示个人待办、最近项目和有权限查看的团队公告。
- 财务账本、API 池与 AI 用量明确显示归属。
- 群头部保留一个菜单，群资料点笔编辑，Enter 或点击空白保存，失败保留输入。
- 备注与昵称独立保存；免打扰、置顶和群昵称显示可分别设置。
- 审批通过后申请人收到系统通知，确认加入后审核人收到通知；已有待确认申请在升级时补发提醒。
- 验证邮箱即可注册，邀请码可选。每个账号都保有个人空间。
- 应用更新使用独立弹窗，与团队公告分开。
- 关闭窗口隐藏到托盘，双击恢复，托盘或账户菜单的退出命令实际退出。
- 默认使用 Unicode emoji，聊天和留言继续支持自有图片及 GIF 表情。

服务器需要升级并执行 core.0039 数据迁移。Windows 客户端使用 0.3.1；只更新客户端不会更新服务器页面。
