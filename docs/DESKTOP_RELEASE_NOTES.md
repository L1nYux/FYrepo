# 知域 0.4.4：两端正式更新渠道修复

- 更新状态区分当前安装版本与正式渠道版本，避免把测试版误报为正式最新版。保留禁止降级和手动确认下载、安装。
- Windows、Apple Silicon Mac、Intel Mac 均准备安装包、校验数据和对应更新清单。Mac 未签名版本继续使用校验后打开 DMG 的安装流程。
- 发布流程检查安装包和清单的版本、文件大小、SHA512，以及所需 ZIP/DMG、blockmap。标签流程生成草稿，正式发布前需要确认。
- 保留 Windows 图标修复、联系人在线状态，以及团队 API 入口、项目与实验可选关联、招聘计划人数和团队硬容量限制。
- 恢复工作台团队管理入口的待审核申请提示。
- 个人手工记账与个人 API 池已停用，历史记录保留；人才市场与积分红包保留。
- 继续使用已确认的服务器 HTTP 连接。

0.4.2 之前的服务器升级包含数据库迁移，需要保留升级前备份。客户端安装与服务器升级分开执行。
