# 知域 0.5.4 验收与交付

## 本轮修改

| 反馈 | 实现与验收入口 |
| --- | --- |
| 文件只有文字链接，不能预览 | 会话中的文件卡片展示名称、类型、大小；点击进入独立预览页面，右上角有图标菜单。 |
| 下载反复选择文件夹、没有进度 | Windows、Android 默认“下载 / 知域”，支持进度、取消、重试、已下载文件复用；浏览器网页仍遵循浏览器下载设置。 |
| 拍摄和相册图标不齐、确认出现网址 | 工具使用统一尺寸 SVG；Android 原生确认不显示页面网址，已有自定义确认组件继续使用。 |
| 每条消息常驻三个点、不能选择文字 | 取消常驻按钮；手机长按、桌面右键打开菜单，提供复制和文字选择；选择文字后保留系统选择交互。 |
| 发送后旧卡片突然出现 | 更新仅作用于客户端已有消息，新消息按创建时间和编号排序，不把历史积分卡片当作新消息插入末尾。 |
| 表情旁边有叉、管理混乱 | 收藏面板首项加号进入独立表情页；长按提供移到前面和取消收藏，整理模式支持多选、计数、移动、删除。 |
| Emoji 被截断、没有分类 | 保留分类、搜索、最近使用；根据宽度计算列数，使用统一图标尺寸，在输入光标处插入。 |
| AI 底部过挤 | 顶部选择模型；输入区保留深度思考、联网、加号和发送/停止。已有模型返回的思考内容继续可展开。 |
| 固定绿色 | “我 / 外观”和桌面设置支持五种强调色；保存到本机，覆盖导航、按钮、开关与原生手机导航。 |
| 招聘无法撤回、招满仍展示 | 管理入口支持编辑、暂停、恢复、关闭；暂停或关闭时不继续公开招聘，招满后不再接受申请；历史申请保留。 |
| 无法退出或解散单人团队 | 所有者可解散任意自己拥有的团队；普通成员可退出；所有者继续提供转交入口。解散关闭邀请、招聘与凭据，保留历史业务和费用记录。 |
| 桌面每次切换都重新加载 | 保留主导航页面组件、滚动位置和输入；业务修改使相关缓存失效，心跳不再清空消息缓存。 |
| 离线需要另找入口 | 桌面离线启动恢复上次账号，从原入口看已缓存页面；恢复连接保留当前页面，退出账号删除授权快照。 |

此前 0.5.3 已完成的团队优先工作台、无团队引导、统一私信、公告删除、独立添加朋友/发起群聊/扫一扫、相对日期显示继续保留。

## 自动验收

- 完整后端回归；另外覆盖文件权限、撤回和隐藏消息、招聘状态、无团队表情、团队解散及计费归属。
- 81 项桌面单元检查：缓存、下载、导航和账号隔离。
- 三组真实 Electron UI 验收：消息、AI 流式输出和停止、失败重试、额度及账号找回。
- 实际桌面冷启动验收：页组件复用、草稿和滚动保留、离线重启、后台重连、退出清理。
- 45 组 360/390/1200 像素页面渲染，无横向溢出或脚本错误；四组消息/表情/文件交互验收。
- Android Java 编译、APK 原签名证书校验、Windows NSIS 构建。

最终测试结果和包校验值见交付目录的 DELIVERY.json 与 SHA256SUMS.txt。

## 部署与限制

客户端和服务器需要同步到 0.5.4。本机 Windows 已更新，生产服务器尚未由本任务部署。

将 zhiyu-upgrade-0.5.4.py 复制到原服务器 /tmp 后执行：

```bash
sudo python3 /tmp/zhiyu-upgrade-0.5.4.py --apply
```

不带 --apply 时只准备升级。升级脚本先备份数据库、附件、SMTP 和 API 配置，检查独立迁移副本，再切换服务。

Office 文档预览需要 LibreOffice、bubblewrap 和字体。升级准备阶段安装组件，并以 workbench 用户执行实际隔离转换探针；探针失败时停止准备，不切换生产服务。本轮本机 Windows 没有 Linux 转换环境，未宣称真实 Linux Office 转换已经通过。

未进行 Android 真机、生产服务器部署、公开发布或 macOS 打包。Windows 安装包没有商业代码签名。MiniMax 待核对调用和账单未自动重发或修改。
