# 科研工作台 0.2.13

## 所有助手工具共用完成检查

- 搜索互联网、读取网页、读取账户背景、搜索工作台、读取资料详情和提取附件全部记录实际状态，区分成功、空结果与错误；没有实际操作不能把一句“我来查查”当作完成。
- 补齐 MiniMax、千问、智谱等已知文本模型缺少工具能力字段时的识别；明确的厂商能力声明优先，未知代理不猜测能力。已有管理员设置保留。
- 用户明确指定的搜索请求、网址、资料类型 / 编号和附件编号可由应用通过现有鉴权读取，再供模型整理；工具接口未启用的模糊工作台查询明确提示换模型或启用工具。
- 明确工具请求没有执行，或回复仅有开场白时，最多进行一次纠正。普通聊天不会增加这一轮；断流、输出截断和费用待核对不会自动重试。已发生的调用仍照常计量。
- 同一轮相同工具与参数复用已读取结果，包括失败结果；不反复请求同一失败来源。短追问“？”或“继续”保留原明确工具请求。
- 网页与附件、工作台资料分别使用对应数量和状态；未完成的消息提供已有的重试按钮。

## 检查与更新

- 417 项 Django、48 项 Node、5 项并发、10 套 Electron 界面检查。新回归覆盖多厂商、明确能力关闭、权限失败、空搜索结果、重复读取、开场白纠正上限、输出截断与费用待核对。
- 验证使用隔离数据和模拟接口，没有真实模型费用或验证码邮件。
- 此修复主要在服务端生效，须执行本版保留数据升级；core 仍为 0022、aihub 仍为 0014，无新增数据库迁移。客户端升级保留原配置。
