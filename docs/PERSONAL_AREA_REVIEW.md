# 0.4.0 个人栏目迭代

## 使用入口

- 顶部增加“我”，进入个人主页、记账、个人 API 用量与连接、人才资料和设置。
- 个人记账只提供收入、支出和收支结余。输入金额即可保存；备注可留空，日期默认今天，项目和凭证在补充信息中。
- 工作台的“团队财务”先列出自己的团队，再进入对应团队的账本或经费申请。
- 通讯录在一个列表中展开新的朋友、联系人、群聊和团队联系人；搜索时展开各组。
- 导航在具体项目、比赛或实验中只突出当前条目，不同时高亮分类入口。

## 数据与权限

“我”的每次请求都按当前登录者选择个人空间，不依赖最后使用的团队，不改动团队选择的会话。个人记账复用已有账目数据，不需要迁移；历史 API 等类型的账目保留原类型并可继续编辑。团队记录及其他个人的记录不能通过个人记账地址读取、修改或删除。

个人记账删除仍进入回收站。团队经费申请继续保持审批流程；个人空间不能创建团队经费申请。项目、比赛和实验继续使用统一入口与归属标签，本轮没有强制个人使用团队审批流程。

## 客户端与服务端

本机已安装客户端检查结果为 0.3.1。桌面顶部和资源树属于客户端自身代码，单独升级服务器不会替换这些界面。此次修改包含网页和客户端两部分，均需更新才能使用完整入口。

客户端构建仍标为 0.4.0 候选版；构建或上传源码不代表已经安装客户端、升级服务器或发布安装包。
