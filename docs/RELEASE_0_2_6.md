# 0.2.6 更新说明

## 桌面体验

- 固定的工作台导航由客户端直接呈现。外观、能力模块、服务器连接、关于与更新仍使用本机配置；打开这些设置不等待服务器页面。
- 先准备本地界面，再确认登录状态。账户和导航一起显示，业务页面的样式、字体、主题与布局准备好后，在内容区域展示。
- 使用现有团队 Logo 制作轻微呼吸和沿图形流动的高亮。主题随本机设置变化；系统要求减少动画时显示静态图标。
- 页面加载期间保留本地导航与账户，允许切换本地设置。三秒后说明等待原因，三十秒超时提供重试；错误页面不直接展示。
- 项目与任务名称继续来自服务器，只在当前登录会话中保留；退出或更换账户时清空。客户端固定导航不会代替服务器权限检查，也不支持离线修改业务数据。
- 加载准备依据组件就绪信号，没有人为加入等待时长。旧页面迟到的信号不能释放新页面，返回历史不会因异步加载而重复追加。

## 调试结果

- 桌面逻辑：21 项，包括加载超时、失效信号、重试、本地组件就绪和导航数据校验。
- 实际 Electron 加载流程：19 项，覆盖慢网络、固定导航、本地设置即时打开、主题切换、返回历史、HTTP 500、退出与重新登录、连接失败与恢复。
- 原有实际界面回归：16 项，覆盖账户布局、邮箱登录提示、邮箱提醒、手机找回密码及财务删除确认。
- Django 回归：207 项通过。测试使用独立数据、模拟服务器及测试邮件，没有向真实成员发送邮件。

## 更新方式

安装 0.2.6 桌面客户端。已运行 0.2.5 的团队服务器无需再次升级；本版没有生产数据库或 SMTP 配置变更。客户端原有设置和登录会话保留。

Windows 安装包未签名；macOS 安装包仍由 GitHub 构建流程生成，本机没有验证 macOS 的实际运行效果。
