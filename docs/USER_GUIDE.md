# 知域使用说明

适用范围：0.4.3 团队优先版本。桌面客户端与服务端升级时应使用同一版本。

## 注册与个人账号

1. 在登录页选择“邮箱注册”，填写工作台号、邮箱、昵称和密码。
2. 获取邮箱验证码并完成验证。邀请码可选，没有邀请码也可以创建个人账号。
3. 注册后创建或加入团队，团队为工作台和 API 调用提供额度与协作空间。

个人账号与团队身份分别管理。被团队移出不会删除已有个人记录或好友关系，也不会撤销其他团队资格。个人手工记账与个人 API 池已停用，旧数据保留。个人可以在密码与安全中申请注销；涉及负责事项时按页面要求先交接。软件管理员另有封禁与注销权限。

## 工作台与资源归属

- 左侧最上方是归属筛选，默认显示全部。
- 项目管理下面列出项目，点击标题进入，点击展开箭头查看任务和子任务。
- 比赛与实验分别列在对应栏目下，条目显示所属个人空间或团队。
- 打开条目自动使用其所属空间。创建项目、比赛或实验时选择归属。
- 概览汇总待办与最近项目。个人概览没有团队公告；在“工作台 → 团队管理”中查看团队概览与公告。
- 团队财务从工作台进入；API 调用集中在 AI 助手模块。助手对话始终属于本人，付费调用必须选择获授权团队。

## 消息与团队

消息左侧功能栏提供聊天和通讯录。团队管理从工作台进入，团队选择与工作台使用同一上下文。

- 聊天：会话、系统通知、未读提示。
- 通讯录：好友、新的朋友、群聊、团队联系人。
- 工作台 → 团队管理：选择团队，管理成员、HR 招募、加入申请、邀请与团队设置。
- “＋”可以添加好友、发起好友群或有资格创建的团队群。

好友私聊与好友群不要求双方在同一团队。团队默认群与正式成员资格同步；不单独添加没有团队资格的成员。

### 群资料

点击聊天右上角菜单打开群资料。点击字段旁的笔进入编辑；Enter 或点击空白保存，Esc 取消，失败保留输入。

- 群名称与公告由有管理权限的人编辑。
- 群备注、自己的昵称、置顶、免打扰与昵称显示为个人设置。
- 普通群“＋”选择可邀请的人，“−”多选移出；群主与管理员的操作范围由权限确定。
- 团队默认群“＋”进入入队邀请，“−”先选成员，再处理团队资格与事项交接。入队邀请及团队群加人都要求 HR；管理员也需单独授权，只有所有者可授予或撤销 HR。
- 成员列表可以搜索。更新成员后，当前聊天输入和附件仍保留。

### 输入与表情

输入工具在左侧，发送在右下角。电脑 Enter 发送，Shift + Enter 换行；触屏回车换行。

点击表情按钮打开分类、中文搜索、最近使用与肤色选择。收藏页可上传图片、GIF，或管理收藏。选择收藏表情后先在输入区预览，可以取消；点击发送提交。

项目、任务、成果的留言使用同一个表情面板。选收藏表情会作为留言附件加入，也可以只发送图片。发送失败会保留输入；文字草稿按账号和会话记忆。跨页面离开聊天前，应先发送或另行保存尚未发送的附件。

## 团队申请与权限

在“发现 → 团队广场”查看公开招聘并提交申请。本人主动提交的申请通过后直接入队，无需再次确认。定向合作邀请则由本人接受后生效。进度在“聊天 → 系统通知”提示，侧栏显示未读数。

团队所有者、管理员和成员是团队内的身份；个人账号、软件管理员与项目负责人是不同层面的权限。团队管理中按成员配置团队项目、实验、财务、API、公告和招募等权限。负责事项仍由项目或任务负责人处理，移出或注销前按要求交接。

## 人才与合作

“发现”保留团队广场、人才市场、我的申请、合作邀请；人才资料编辑统一在“我”。人才资料默认不公开，只有本人开启后才进入市场；可以关闭展示或屏蔽某个团队。

每条新招聘须设置计划人数，正式入队达到计划后自动结束。团队满员时，即使招聘未结束也不能继续入队。历史招聘需先由 HR 补设计划人数。

团队可选择公开招聘、仅定向邀请或暂停招募。选择“仅定向邀请”后不接受公开申请。合作邀请会写明负责事项、条件、有效期，以及加入整个团队还是仅参与某个项目。

仅项目合作可查看该项目、参与任务、留言和提交成果，不会自动获得团队其他项目、财务或 API 池权限。项目负责人可结束授权。学历与执照认证暂未接入，人才资料由本人填写。

## AI 与经费

- AI 模块提供“API 调用”，集中显示 API 地址、自己的调用 Key、可用模型、团队余额和用量。团队必选，项目和实验可选。
- 可生成只关联团队、绑定项目或绑定实验的 Key；已有实验绑定继续生效。个人 API 池和个人厂商连接配置已停用。
- 在助手中选择已授权团队作为扣费来源，切换来源不会切换或公开个人对话。
- 团队只能查看费用与用量，不能通过团队管理查看个人提示词、回答和附件。
- 助手可读取本人有权访问的多个项目；选择团队扣费不会增加资料权限。
- 团队撤销成员或 API 池资格后，下一次付费调用前重新检查；已经发生的费用仍正常结算。
- 团队可发放、补发点数或重置额度，积分红包入口继续保留。经费报销须附用量凭证，预支仍为独立申请类型，不附对话正文。
- 同一用量不能重复报销；申请驳回后可重新提交。额度补助审核通过后补入团队额度；现金审批只登记账目，实际付款由团队自行处理。

## 设置与软件管理

账户设置提供资料、公开资料、密码与安全。应用设置提供外观、能力模块、连接和关于与更新。

有软件管理权限的人进入软件管理后，左侧改为账号、团队容量、账号操作记录等栏目；不再显示项目导航。返回按钮回到先前页面。

- 团队管理只能处理对应团队成员资格与授权。
- 软件管理负责个人账号的封禁、解封、注销及团队容量。
- 界面仅显示当前账号有权使用的栏目，服务端仍会检查每次操作权限。

## 更新与退出

应用更新有独立弹窗入口，与团队公告分开。“关于与更新”分别显示桌面版本和服务端版本。安装新客户端不会自动升级服务器。

右上角关闭窗口会隐藏到托盘。双击托盘图标恢复；托盘菜单或账户菜单的“退出应用”才真正关闭。退出登录只结束账号会话。

本版变化见 [0.4.0 更新说明](RELEASE_0_4_0.md)。0.2.5 的历史细节保存在 [旧版使用说明](USER_GUIDE_0_2_5.md)，其中账号与导航规则不适用于本版。

### 联系人在线状态

私聊列表、标题和通讯录显示在线/离线，仅好友及有效队友可查看。沿用最近 90 秒活动心跳判断；无权查询时显示状态未知，不保存活动历史。
