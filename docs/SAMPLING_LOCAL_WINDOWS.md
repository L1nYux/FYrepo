# Windows 本地测试正式版

无需合并 PR、GitHub 管理员权限或 Git 命令。先解压完整源码包，进入能同时看到 `manage.py` 和 `START_SAMPLING_LOCAL_WINDOWS.cmd` 的目录。

1. 需要 Python 3.11+；启动文件支持常见的 Anaconda / Miniconda 安装位置。
2. 如果旧网页占用 `127.0.0.1:8000`，先在旧运行窗口按 Ctrl+C 停止。
3. 想沿用旧工作台账号、项目及附件时，在首次启动前，将旧项目的整个 `data` 文件夹复制到新项目根目录，与 `manage.py` 同级。保留原目录作为备份。
4. 双击 `START_SAMPLING_LOCAL_WINDOWS.cmd`。首次安装依赖需要联网；不需要手动编辑 `.env` 或 `settings.py`。
5. 空库会提示创建自己的管理员；输入密码时终端不显示字符。已有活跃管理员的数据库直接沿用原账号。
6. 浏览器自动打开 `http://127.0.0.1:8000/sampling/`。尚未登录时先在公开页面右上角登录，再进入左侧样本库。

启动器自动配置本地密钥、数据库目录、HTTP Cookie 和开发模式，执行数据库迁移及 Django 检查，并同时启动真实工作台与 PDF 转 Markdown worker。再次启动复用本地密钥、账号及业务数据，不生成示例数据。已有数据库在迁移前备份到 `data/backups/`。

测试期间保持启动窗口打开。停止时按 Ctrl+C；再次启动继续双击同一文件。若失败，窗口会停留，保留完整错误输出以便排查。重启需要重新登录属于正常情况。

先测试新建抽屉、空表单错误、可选项目关联、保存摘要、编辑回填和深浅色模式。真实采集及冻结需要本人采集或上传真实题录；空候选池不能冻结。

测试知网采集时，再双击根目录的 `START_CNKI_AGENT_WINDOWS.cmd`，将终端连接码粘贴到工作台。也可从登录页或采集面板下载并完整解压独立采集器 ZIP，运行同名启动文件，包内自动配置当前工作台地址。本人机构登录在本机完成。采集器单独运行；本地网页与 PDF worker 由主启动器同时启动。

转换 PDF 前需采集真实题录、复核并冻结样本集，再在“全文与 Markdown”上传匹配正式编号的 PDF。文字层提取不包含 OCR；查看转换报告并核对真实文本。

代码源码包不包含数据库、私有上传、默认账号、真实论文、连接码或登录资料。只访问本机 `127.0.0.1:8000`，不会自动部署到线上或推送 GitHub。

启动器的 Python 入口是 `tools/start_sampling_local.py`。非 Windows 平台也可运行该脚本；`--check-only` 仅进行安装、迁移和检查，`--data-dir` 可指定另一个本地数据目录。

既有 Linux 启动验收覆盖安装、迁移、账号与密钥保留、数据库备份及 Web / worker 启停。本轮按最新 main 的 Web 与 Agent 环境各运行 672 项回归，均通过，3 项既有 AI 浏览器可选测试跳过；另用真实 Chromium 验收 Sampling 页面、公开下载及本机连接。详见 `docs/SAMPLING_ONBOARDING_2026-10-09.md`。Windows CMD 双击与本人知网权限仍需在 Windows 电脑上验收。
