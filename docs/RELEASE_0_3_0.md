# 知域 0.3.0：个人空间与团队公账户

这是未合并开发分支的重构候选版。Preview 暂未配置，本轮不执行 Production 部署、Merge 或正式 Release。

## 三种身份

- **个人账号**：工作台号用于登录与加好友；昵称用于交流。个人空间可独立管理项目、任务、实验、财务和 API 池。
- **团队成员资格**：个人加入团队公账户，在该团队内按所有者、管理员或获授能力操作。一个人可以加入多个团队，也可以拥有自己的团队。团队不提供共享登录密码。
- **软件管理身份**：由软件所有者授予，管理平台账号和团队准入、规模；不会因此获得团队私有业务数据的访问权。

个人账号被封禁与团队成员被移出是不同操作。移出某个团队只撤销该团队的资格，不影响个人空间、好友、其他团队与个人 AI 配置。

## 导航与团队

- 工作台的空间选择器用于切换个人空间和团队公账户。首次升级保留原工作团队，新注册账号进入个人空间。
- 「我的团队」展示已加入团队、创建团队、寻找团队和加入入口。
- 消息里的「我的团队」用于团队成员与管理，保持在消息导航中，不改变工作台已选择的空间。
- 团队所有者可分配公告、邀请、招募、财务、项目、实验和 API 池管理能力。普通团队成员只有自己的报销申请，不能读取团队账本或其他人的报销凭证。
- 团队默认容量来自 `WORKBENCH_DEFAULT_TEAM_LIMIT`（默认 10）；软件管理可调整。成员不能自行扩大团队人数上限。
- 团队可维护名称、公开介绍及招募职位；申请人可保存简历并申请加入。再次申请会显示待审核提示；移出后重新加入不恢复以前的管理授权。

## 消息

- 好友关系属于个人；同团队成员可直接私聊，跨团队需要好友申请。
- 好友与同事私聊使用同一界面；支持附件、图片粘贴、表情、内容引用、撤回、重新编辑、免打扰、清空自己的记录与查找历史。
- 普通好友群独立于团队。群资料、群成员、群公告和个人群昵称在右侧面板管理。
- 每个团队保留一个默认团队群，复用原内部聊天室。原公共聊天室保留为只读历史，保持原成员范围。
- 原私聊迁移为个人会话，保留原作者、时间、引用、附件与隐藏状态。查看原团队引用或操作团队积分仍需要原团队的权限。
- 工具保留在输入区左侧，发送位于右下角；Enter 发送，Shift + Enter 换行。

## 注册、封禁与注销

- 测试阶段允许无邀请码个人注册，但须通过邮箱验证码；团队成员邀请仍可直接引导加入。
- 正式运行必须配置可发送邮件的 SMTP。未配置时如实提示失败，不把未验证邮箱当作已验证。
- 软件管理可封禁、解封、重置个人密码或注销账号。重置后旧会话与 API Key 失效，临时密码有效 24 小时，登录后必须设置新密码。
- 个人可导出自己的数据并注销。注销须输入当前密码与「注销」，先交接或解散拥有的团队和群。
- 注销关闭个人空间、取消未完成的 AI 工作、撤销令牌、清除个人存储的 API 密钥与公开资料；团队记录保留，历史作者显示「已注销用户」。其他团队的 API 密钥保留。
- 个人记录进入封存状态；当前未提供自动物理删除期限。团队业务记录和历史审计不能随个人注销删除。

## 升级边界

数据库迁移到 `core.0038_team_disbanded_at` 和 `aihub.0018_alter_allowance_workspace_and_more`。原账号、密码、业务主键、余额和五个元老账号的旧登录兼容保留。

升级说明见 [0.3 架构与迁移](ARCHITECTURE_0_3.md)。客户端覆盖安装保留连接配置；新功能需要对应的 0.3 服务端。仅安装客户端不会自动升级服务器。
