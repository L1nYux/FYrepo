## 服务端升级

将本目录的 `zhiyu-upgrade-0.6.0.py` 上传原 Ubuntu 服务器。

```bash
sudo python3 /tmp/zhiyu-upgrade-0.6.0.py --apply
```

脚本备份原数据库、附件、环境配置和服务配置，先在数据库副本执行迁移，再切换服务。不要重新初始化或清空数据库。现有账户、SMTP 和 API 密钥由原数据目录与环境配置保留。Office 预览需要 LibreOffice、bubblewrap 和字体，升级脚本包含安装步骤。
