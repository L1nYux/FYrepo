# 科研工作台 0.2.16

## 导航与公告

- 网页和桌面的工作台导航支持展开 / 收起：232px → 68px，240ms 轻微过渡，记住选择；收起时只保留居中的图标与悬停菜单名，项目树隐藏，主内容填满剩余空间。
- 展开时增大文字和图标并压缩横向空白，保持白灰风格与当前菜单高亮。
- 公告采用独立卡片，卡片之间留白 20px、内部留白 24px，保留轻边框和圆角。

## 成员资料与管理

- 新增成员资料库：搜索姓名、账户名、公开昵称与研究方向，显示身份、负责项目及任务数量。非公开研究方向和简介不会被检索或显示。
- 点击头像或姓名打开统一资料卡，包含公开资料、负责项目及发消息入口，跟随浅色、深色主题。管理操作只对管理员开放。
- 管理员可为未绑定邮箱的成员重置密码：生成 24 小时有效的临时密码，仅在本次操作页面展示；撤销旧登录状态、个人 API Key 和未使用的邮箱验证码。成员下次登录必须设置自己的新密码。
- 管理员可删除成员账号：准确输入账户名确认，有负责事项时先交接给在用成员；API 池负责人必须交接给管理员。不能删除当前账号，不能移除最后一位在用管理员。
- 删除后取消登录资格、清除个人标识，保留历史项目、实验、财务和聊天资料。已有私聊可只读查看，不再允许发消息或转赠点数。

## 检查与升级

- 452 项 Django、51 项 Node、5 项 SQLite 并发检查及 11 套 Electron 界面检查。Linux、Windows CI 均为发布前置检查；模拟服务不产生真实 AI 或 SMTP 费用。
- core 新增 `0023_member_account_lifecycle`，aihub 仍为 `0014_budgetweek_base_limit_recorded_and_more`。**团队服务器也必须升级**，成员资料库与账号管理才能使用。
- 使用保留数据升级脚本，备份后执行迁移、收集静态文件和重启服务。桌面覆盖安装保留本地配置与仓库文件。
- Windows 继续应用内下载并重启安装；免费 Mac 更新继续下载校验后的对应架构 DMG，打开后由成员拖入应用程序目录。
- 本轮不包含多团队平台扩容。
