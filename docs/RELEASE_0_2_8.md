# 0.2.8 头像、聊天管理与积分红包

## 变化

- 账户资料上传静态 PNG、JPG、WebP，最大 5 MB。图片验证后去除元数据、按方向裁切为方形头像，最大 512 像素。可恢复默认头像；未公开资料的头像不向访客开放。
- 消息导航固定为深色，选中聊天高亮，标题显示成员姓名与头像。
- 每个会话独立免打扰，免打扰会话不增加总未读提醒；其消息与会话未读数量保留。
- 查找聊天记录支持关键词、日期、发送者、图片、附件和引用，点击结果定位前后文，可返回最新消息。
- 删除单条、清空历史、移除会话仅影响自己；清空和移除要求确认。收到新消息时，移除的会话会重新出现。积分流水不随个人聊天记录删除。
- 私聊支持积分转账和红包，群聊支持均分和拼手气红包。仅可转赠额外点数，基础周额度和 AI 调用中的预留点数不可转赠。发送立即扣除并托管，领取进入对方额外余额；24 小时未领取部分退回，未领取转账可主动退回。
- 重试同一次发送或领取不重复扣点或入账；后端使用与 AI 计费相同的数据库写入锁防止超发。
- AI 回复渲染常用 Markdown，资料引用显示标题与卡片；原始 HTML 不执行。对模型提供的资料去除内部展示地址，保留真正所需的工具参数。提示词要求先回答问题，避免无关的资料清单。

## 升级

使用 `deploy/upgrade_preserve_data.sh --apply`，以 root 身份运行。升级会备份数据库、附件、邮件环境配置、API Key 和服务配置，迁移 `core.0019` 与 `aihub.0010`。失败按原脚本回滚。不要重新安装数据库或重新创建账户。

新增 `research-workbench-gifts.timer`，每分钟检查到期退款，另有余额查询及下一次 AI 调用前的补偿检查。定时服务使用应用既有数据目录与配置，调用 `expire_point_gifts`，不联系模型厂商。

头像图片处理新增 Pillow 依赖。桌面更新使用新安装包覆盖安装，原有本地配置保留。当前分支构建不代表正式自动更新已发布；macOS 包未签名、公证，未在实体 Mac 上验证。
