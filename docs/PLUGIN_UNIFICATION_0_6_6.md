# 知域 0.6.6：内置能力统一管理

## 入口与设置

商城包含五个 AI 插件和三个电脑版工具：本地仓库、远程仓库同步、桌面 AI 入口。电脑顶部“发现”、左侧“我”与设置中均可直达商城。旧的“能力模块”开关移除。

AI 插件沿用账户设置，三个电脑工具沿用 `connections.json` 内既有设置，不新增第二份开关、不重置旧值。电脑工具详情注明“本机”，手机和网页可查看用途，不能替另一台电脑修改设置。远程同步需要已启用的本地仓库；桌面 AI 入口只管理顶部导航行为，不改变服务端插件或团队权限。

三项电脑能力使用与服务端共用的静态目录。Native 桥接只接受已登记插件 ID 和布尔启停值，仅允许当前登录客户端的当前主页面在商城地址调用。其他页面、外部页面、子框架和已退出的会话不能写入。商城不获得任意文件、命令、服务器地址或仓库提交权限；打开插件后仍走原工作台。

## 修改任务

任务协作插件新增“修改任务信息”。用户在授权项目中授予这项操作后，Agent 可修改进行中任务的名称、说明、负责人、参与成员和截止日期。先读取任务版本及项目成员，保存前再次校验版本、项目和成员资格。未提供的字段保留；重复操作复用持久回执。

这项能力不会自动添加到旧授权中，需选择允许的操作。仅有任务参与权限不能授予项目管理操作。插件关闭、权限失效、任务归档、已提交或已结项时拒绝写入；不提供修改进度、审核状态、项目归属或创建者的参数。人类编辑与 Agent 使用同一任务表单和共享保存命令。

Agent 保存后的实际回执通过任务轮询响应通知桌面缓存。收到新回执才使相关业务页面重新加载；同一回执重复轮询不重复清除缓存。外部页面、无效标识、其他账户的任务或切换账户后迟到的响应不能改变当前页面缓存。

## 范围与升级

此版不新增数据库迁移。客户端覆盖安装保留连接与外观设置，商城页面与任务工具需要同步升级服务器。服务器单文件升级脚本为 `zhiyu-upgrade-0.6.6.py`，上传 `/tmp` 后运行：

```bash
sudo python3 /tmp/zhiyu-upgrade-0.6.6.py --apply
```

继续保留 PR #10、#11 和既有 API 中转功能。第三方插件安装、MCP、项目创建等其余 Agent 操作、通用 Files、Realtime 和多媒体接口尚未完成；整体业务页也尚未全部改为组件数据更新。Android/iPhone 真机及真实付费供应商验收仍未完成。自动验证证据见发布包 `BUILD.json`，校验值见 `SHA256.txt`。
