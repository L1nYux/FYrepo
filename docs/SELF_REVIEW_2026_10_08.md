## 最新确认：API 池、加密连接与唯一团队采样

### 产品规则与修复

- 团队 API 池即日常免费预支来源，继续使用现有额度分配、补发点数和重置功能。不新增“额度预支申请”类型或表单。
- 个人自付用量的额度报销称为“API 用量补发”，必须附个人用量凭证；表单、提交服务、审批及恢复流程都重新校验。无凭证的历史待审额度报销不会直接发放，需重新提交凭证或由池管理者直接分发日常额度。
- 用量凭证只展示模型、时间、费用，不展示对话。重复审批只补发一次，额度补发不写现金账本。原有现金费用报销保留。
- 客户端默认 HTTPS，校验证书，不自动降级。保存过的远程 HTTP 地址也在启动首次请求前征得明确确认；临时许可只保存在当前进程，取消不会发送状态请求或改变连接配置。本机回环测试服务可使用 HTTP。
- 用户确认现有旧采样数据属于唯一团队。新增迁移将旧样本归该团队；多团队或关联项目归属冲突时中止，不猜测归属。迁移仅补归属字段，不改变冻结状态、抽样指纹或研究参数；尚未对正式数据执行。
- 样本列表、直接地址、编辑、克隆、导入、采集接口、全文状态与下载均检查有效归属；退出团队或变成团队访客后不能打开团队样本。个人样本仅本人可见，软件管理员也不能借后台读取外部团队的样本。
- 样本操作按记录实际归属执行，不修改记住的个人/团队空间；克隆保留归属，关联项目和来源版本不能跨归属。
- 原生桌面工作台加入样本库入口，并接入现有资源归属筛选、选中状态；列表显示归属标签，创建表单显示保存位置。
