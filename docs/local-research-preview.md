# 本次更新摘要

完整操作及权限说明见 [功能与使用说明书](USER_GUIDE.md)，部署步骤见 [运维说明](MAINTENANCE.md)。

## 界面

- 访客使用独立浅色展示页；工作台默认中性灰深色，支持浅色切换。
- 全宽统一顶栏切换「工作台 / 消息」，右上角账户菜单承载设置、公开资料、密码及外观。
- 项目概览、任务、成果分页签；账本和报销分页签，减少单页内容堆积。
- 任务讨论与成果按时间显示，任务信息放在可折叠详情区域。

## 项目、比赛及实验

- 保持项目 → 母任务 → 子任务三级，任务支持多人协作及设计 / 过程 / 分析 / 其他分类。
- 可选关联比赛，比赛汇集跨项目的关联任务及管理员选用成果，支持归档恢复。
- 实验使用通用目的、方法、结果、结论及自定义参数，不要求模型 / Prompt 字段。
- 参数模板、实验文件、搜索、我的记录、2–3 条对照；任务提交时可同时新建实验。
- 沿用原实验公开审批；公开记录的实验附件也向访客开放，修改后重新审核。

## 消息与引用

- 公共讨论、成员私聊、文件及未读提示；页面和私聊文件仅向参与双方开放。
- 输入框「＋」添加附件或搜索引用任务、实验、财务、报销申请及公告。
- 每条最多 5 条引用，可仅发送卡片；查看权限来自原记录，不因引用而放宽。
- 点击任务 / 实验卡片进入原详情；财务 / 公告有只读详情。不可用引用隐藏原详情信息。
- 聊天不自动写入任务留言，也不产生网站业务审计。
