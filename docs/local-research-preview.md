# 本次更新摘要

完整操作及权限说明见 [功能与使用说明书](USER_GUIDE.md)，部署步骤见 [运维说明](MAINTENANCE.md)。

## 界面

- 访客使用独立浅色展示页；工作台默认中性灰深色，支持浅色切换。
- 全宽统一顶栏切换「工作台 / 消息」，右上角账户菜单承载设置、公开资料及密码；主题由顶栏开关切换。
- 项目概览、任务、成果分页签；账本和报销分页签，减少单页内容堆积。
- 任务讨论与成果按时间显示，任务信息放在可折叠详情区域。

## 项目、比赛及实验

- 保持项目 → 母任务 → 子任务三级，任务支持多人协作及设计 / 过程 / 分析 / 其他分类。
- 可选关联比赛，比赛汇集跨项目的关联任务及管理员选用成果，支持归档恢复。
- 实验使用通用目的、方法、结果、结论及自定义参数，不要求模型 / Prompt 字段。
- 参数模板、实验文件、搜索、我的记录、2–3 条对照；任务提交时可同时新建实验。
- 沿用原实验公开审批；公开记录的实验附件也向访客开放，修改后重新审核。

## 消息与引用

- 公共讨论、成员私聊、文件及未读提示；页面和私聊文件仅向参与双方开放。
- 输入框「＋」添加附件或搜索引用任务、实验、财务、报销申请及公告。
- 每条最多 5 条引用，可仅发送卡片；查看权限来自原记录，不因引用而放宽。
- 点击任务 / 实验卡片进入原详情；财务 / 公告有只读详情。不可用引用隐藏原详情信息。
- 聊天不自动写入任务留言，也不产生网站业务审计。

## 数据与发布

新增迁移 `0005_integrated_public_experiments`、`0006_research_competitions_messages`、`0007_chat_content_references`（主分支此前只到 `0004`）。同一迁移链正常升级保留账号、任务、实验、财务等数据。

后续补充迁移 `0008_expenseclaim_project`、`0009_financeentry_project_project_budget`、`0010_normalise_user_email` 与 `0011_emailverificationcode`：报销申请与账本记录都可以可选关联项目，项目可以设预算，项目页因此能给出成本汇总；账号邮箱统一小写并唯一化，支撑两条找回密码路径——登录页的邮箱链接（进不来时用）与账户设置里的邮箱验证码（已登录、只忘了旧密码时用）。同一迁移链直接 `migrate` 即可，历史报销与账目保持「未关联项目」，历史邮箱只做大小写归一。

两条找回路径都需要生产环境配置 SMTP（见运维说明）；`WORKBENCH_DEBUG=1` 时用控制台后端，重置链接与验证码直接打印在 runserver 输出里，本地无需任何邮件配置即可走通。

本地预览配置、数据、账号密码和备份位于仓库外，不上传。采用 Django、SQLite 和 HTTP 轮询，不新增服务依赖。仓库自带自动化测试（`manage.py test core`，175 个用例全部通过），生产部署仍未执行。
