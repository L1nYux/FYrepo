# 0.2.5 更新说明

## 变化

- 桌面登录提示改为「用户名或邮箱」；未绑定邮箱在头像及账户资料旁显示小红点，绑定后消失。
- 登录页和账户设置共用邮箱验证码找回页面：发送验证码后，在原页填写验证码及新密码。手机使用单列页面、16px 输入框、触屏按钮及可滚动提交；允许粘贴验证码。
- 验证码单次使用、10 分钟有效、最多 5 次尝试；重发有 60 秒冷却及发送上限。更换邮箱、重新发码或其他浏览器不能复用旧流程。密码不合规时保留正确验证码。已登录改密保留当前会话，其他设备的旧会话失效。
- 保存账户资料后的跳转保留桌面布局与主题，设置卡片使用可用宽度，嵌入网页隐藏重复导航。
- 管理员可删除账目和报销；成员可删除自己的待审报销。删除进入回收站，余额和项目成本同步更新；恢复会重新计入。关联账目与报销一起处理。
- 彻底删除先展示关联范围，再弹窗确认；默认取消，确认仅提交一次，服务端仍校验签名及权限。

## 调试

- Django 后端：207 项（core + aihub），覆盖重置流程、密码校验、邮箱变化、会话失效、权限、回收站、统计及历史兼容。
- 桌面逻辑：11 项，包含导航与助手页面逻辑。
- Electron 实际渲染：16 项，包含 POST 跳转、主题同步、360/390 像素手机页面、键盘滚动、小红点及删除确认。
- 迁移一致性检查与 Git 空白检查通过。

自动化邮件使用测试收件箱，没有向成员真实发信。生产 SMTP 的真实送达仍需升级后从页面确认。注册和绑定邮箱的归属验证没有在本版新增。

## 升级

客户端安装 0.2.5；团队服务器另运行 `deploy/upgrade_preserve_data.sh --apply`。脚本备份并保留账号、密码、附件、API 密钥及已有 SMTP 环境配置；core `0017` 增加账目与报销的回收站字段。客户端更新不会自动替换服务器代码。
