# 科研工作台 0.2.17

## 图片输入

- AI 助手支持粘贴截图、拖放和选择图片，每条最多 4 张。
- 支持识图的模型显示“识图”标记；不支持时明确提示切换模型，保留文字和图片，本次不发起调用、不扣 AI 点数。
- 图片随对话历史保留，恢复和重试保持原图；删除对话会清理不再使用的图片。
- API 池高级设置可指定模型识图能力，默认按已核实型号或目录元信息识别。

## 联网搜索

- 增加国内必应和百度来源，支持备用公网地址、压缩页面及字符集。
- 搜索成功后尝试读取前两个来源正文，区分搜索摘要、已读取页面和失败原因。
- 保留实际来源引用编号、右侧搜索结果面板和内置网页查看入口。
- 网络、验证码或网页结构变化仍可能影响免费公共搜索；服务器可运行诊断命令或配置自己的公开搜索服务。

## 账号

- 修复管理员重置密码页面因来源策略导致的 HTTP 403。

## 安装

Windows 可通过更新入口安装。免费 Mac 版本自动检查和下载后仍需覆盖安装。服务端包含 aihub.0015 数据迁移，须同步升级；仅更新桌面安装包不会更新服务器。

多团队分层系统正在单独改造，本版尚未开放多团队注册与切换。

实现与服务器诊断说明见 docs/ASSISTANT_IMAGES_AND_SEARCH.md。发布前由仓库现有 Linux、Windows CI 执行完整检查；实际服务器网络连通性需要在部署环境确认。
