# 0.2.9：聊天布局、消息导航与免费更新

## 功能

- 聊天侧栏和原生账户栏统一深色；修正嵌入页面顶部空白、气泡对比、间距、操作按钮和手机操作区域。
- 点数最多一位小数，省略尾零；原始积分账本与红包分配精度保持不变。
- 只记住 `/messages/` 与 `/messages/to/<成员>/` 会话地址；引用详情可以打开和返回，但不能覆盖“消息”入口。
- 头像旁更新按钮支持检查、进度、下载就绪标记、失败重试和安装确认。
- Windows 保留 electron-updater 的完整性校验，下载后经确认自动安装并重启，不在退出应用时擅自安装。
- 免费 Mac 按真实架构下载 DMG，清单绑定版本、文件名、大小与 SHA-512；下载和打开前都校验，失败删除临时文件，已经完整下载的缓存可复用。确认后通过系统打开安装包，由用户退出并覆盖应用。
- 标签版本与 package.json 必须一致；Windows 和两种 Mac 架构构建完成后自动发布 GitHub Release 与更新清单。无需 Apple 付费签名。

## 验证

- Django：346 项，覆盖账户、验证码、聊天、红包、API 与显示格式。
- Node：38 项，包括严格消息地址、Windows 更新事件、Mac 清单校验、下载哈希、架构、重试与安装前再次验证。
- 积分并发：5 项，重复发送扣款一次、领取份数约束、重复领取一次、到期退回一次、预留/红包竞争。
- 聊天界面：20 项，含深浅色、手机、桌面嵌入、头像、红包金额和 Markdown。
- 真正的 Electron 主进程：加载门控、账户底栏、AI → 公告引用 → 消息、更新事件推送、取消与确认安装。
- 邮箱与 AI 思考界面：17 项；助手配额和重试界面继续通过。

不调用付费模型、不发送真实验证码、不改真实客户端配置。Mac 安装运行需要真实设备确认；安装替换在测试中使用替身，不在成员应用上强制重启。服务器升级另行执行保留数据脚本，客户端更新不会自动更改服务器数据库。

## 成员使用

Windows 0.2.7 / 0.2.8 可从原“设置 → 关于与更新”获取 0.2.9，之后使用头像旁入口。旧未签名 Mac 手动覆盖安装 0.2.9 一次，以后的版本可由应用自动检查和下载。安装来源统一为 GitHub 正式发布页，Windows、Apple Silicon 与 Intel 各自选择对应包。
