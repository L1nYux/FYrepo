# 0.2.7 更新说明

## 工作台导航

- 保存团队联系方式留在内部设置页，保留保存提示与填写的内容。
- 对外的项目、实验、成员与联系页面通过明确的「预览公开页面」入口，在浏览器或新标签打开。
- 任务等操作的返回地址只接受已知的内部页面。桌面端同时拦截旧服务器指向公开页面的跳转，恢复至刚才的内部页面。
- 已登录时的邮箱验证码找回保留工作台设置布局和桌面主题；未登录时保留手机适配的独立找回页面。修复验证码按钮在部分页面提交时报错的问题。

## AI 消息

- 发送后正文与引用进入消息气泡，编辑框清空引用。
- 启动失败和模型失败在气泡旁提供「重试」，保留原消息与原引用；编辑中的新草稿不会被重试覆盖。
- 断线重试继续查询同一任务，不再自动创建第二次调用；已确认失败的任务需要用户点击重试。
- 启动请求带稳定标识，重复请求返回同一任务。恢复历史时保留失败任务的重试入口；服务端重新校验账户与引用权限。
- 正式模型调用依然可能产生费用，手动重试失败任务的费用以厂商结算为准。

## 厂商余额与套餐额度

- API 池负责人在「连接与模型」查看各连接的余额或套餐额度、更新时间、重置时间与刷新按钮。成员调用点数继续单独统计。
- 直接使用服务端已保存的 Key，不向网页或桌面界面返回密钥。仅识别固定官方域名；额度查询不会发起模型推理。
- MiniMax：M Plan 的 5 小时与周窗口；普通按量 Key 的账户可用余额。支持国内与海外接口，现金币种分别显示 CNY / USD。可选择自动、套餐或按量账户类型。
- 智谱：接入官方客户端使用的套餐配额查询，展示厂商实际返回的配额与重置时间。普通按量账户现金余额暂需在官方后台查看。
- 千问：保留百炼官方后台入口与明确说明。百炼模型 Key 不能代替阿里云费用凭证，不凭本地调用记录推算现金余额，也不将不可查询显示成 0。
- 查询失败保留与当前连接匹配的上次结果并标记；更换连接或 Key 后隐藏旧账户的缓存。打开设置不等待厂商网络，手动刷新最多每 15 秒一次。
- 余额通常属于 Key 对应的账户，多个 Key 可能共享同一账户。套餐能否用于具体应用场景以厂商规则为准。

- Django 227 项通过；桌面逻辑 25 项通过；实际 Electron 加载 23 项、原有界面 16 项、新消息与额度界面 11 项通过。
- 覆盖保存重定向、公开预览、旧服务器兼容、手机宽度、引用清空、重复点击、原任务恢复、权限、余额缓存与认证失败。
- 使用隔离数据、模拟厂商接口和测试邮件；没有向成员发邮件或使用真实 Key 调用模型。真实厂商查询仍需配置对应 Key 后核对。

## API 池目录与价格页优化（2026-10-04）

- 读取模型后按厂商分组，提供厂商、用途、名称与「只看已选」筛选。默认显示助手可用的对话模型；图片生成、语音、视频、向量等用途可以查看，但不能从目录启用到当前助手。
- 「全选」只作用于当前筛选结果，切换筛选保留已勾选模型。首次读取不自动勾选新模型，已有启用选择保留。
- 显示实际调用渠道。百炼渠道返回的智谱等模型，其价格与额度以百炼账户为准。
- 价格页只列出启用连接下的启用模型，待补价格优先；支持名称、连接和价格状态筛选。保存价格后立即更新当前筛选。
- 停用模型与连接移到独立的模型管理区，可搜索并重新启用。原有单价与历史调用保留，直接打开停用模型的价格链接会引导至模型管理。
- 分类优先使用目录的用途信息，并补充已知模型名称规则；没有用途信息的陌生 ID 保留为通用对话模型，不代表已实际验证该模型可调用。
- 验证：Django 234 项、桌面逻辑 25 项、实际 Electron 模型目录与价格页 15 项通过。界面测试模拟 223 个模型，检查隐藏选择、失败保留、价格筛选与手机宽度；未使用真实 Key 调用模型。
- 此补丁没有数据库迁移或桌面运行时变更，更新服务器后网页与桌面中的 API 池页面同步生效。
