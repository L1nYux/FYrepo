# 知域 0.6.5：统一插件商城

## 使用

“发现”和“我”均可进入插件商城；AI 助手顶部也提供“插件”入口。商城包含当前全部内置插件：工作资料、互联网资料、任务协作、文档草稿、实验记录。已有账户的启停设置保留。

搜索插件名称或具体能力，在“全部”和“已启用”间切换。搜索与筛选在当前页面完成。进入详情可查看实际能力与使用方式。插件开关随账户保存，手机、桌面和网页共享；页面恢复或重新获得焦点时刷新状态。

启用提供能力；“执行授权”指定 Agent 可以在哪个项目、在多长时间内、完成多少次操作。两者均须有效。停用不会撤销既有授权，但不会开始新的插件操作。已完成的操作和回执保留。正在提交的写入与停用串行处理，不撤销已经成功完成的业务操作。

## 实验记录

实验插件可创建内部实验记录、更新实验内容、结果、结论和工作状态。权限检查、表单、自动编号和公开审核与业务页面共用。更新前必须读取记录版本；版本发生变化时返回冲突，不覆盖他人的修改。重复执行复用回执，不重复创建或消耗操作次数。

插件不能修改所属项目、公开发布、归档实验、改变人员权限或管理团队。公开记录修改后仍需重新审核。项目已归档、授权已失效、插件已停用或账户权限不足时拒绝操作。

## 实现边界

插件目录来自受信任的服务端注册表；新增注册插件自动进入商城，避免另维护一套内置插件列表。商城与旧版助手插件设置共用账户设置。启停接口要求登录、POST 和 CSRF 校验；不能通过提交任意处理器、用户编号或配置执行代码。

此版本统一了内置插件的展示和管理。尚不提供第三方插件下载、任意代码安装、MCP 连接或插件上传。核心项目、任务、财务等业务页面继续作为业务模块；商城中的条目是 AI 助手的能力扩展。

## API 小修复

增加 `POST /v1/responses/{response_id}/cancel`，仅用于同一 Key 创建的供应商后台 Responses 任务。是否支持取消由上游决定。取消返回确认用量时结算一次；取消失败或缺少用量时保留待核对记录，不推定免费，也不自动重发。查询和取消均检查上游响应编号与请求一致。

本版本保留 0.6.4 的中转接口、请求限制、渠道池、账目及 PR #10、#11 的内容。通用 Files、Realtime/WebSocket、多媒体接口、第三方插件及完整业务 Agent 操作仍待后续版本完成。

## 升级

覆盖安装客户端不会升级服务器。商城、实验插件和后台响应取消需要服务器同步升级。下载 `zhiyu-upgrade-0.6.5.py` 上传服务器 `/tmp`，执行：

```bash
sudo python3 /tmp/zhiyu-upgrade-0.6.5.py --apply
```

单文件内置源码，保留原有备份和回滚流程。Python 与系统依赖安装仍需网络。此版本不新增数据库迁移。

## 验证

发布包内 `BUILD.json` 和 `SHA256.txt` 记录对应源码、验证结果和文件哈希。业务测试、页面检查和中转验证使用隔离账户、数据库及模拟供应商；真实付费模型、生产服务器部署与 iPhone 真机安装不在自动验证范围内。
