# 知域 0.2.20 开发分支说明

## 账号与名称

- 应用更名为「知域」，网页、桌面与安装程序采用相同图形 Logo。
- 工作台号是唯一登录和加好友标识，昵称用于聊天展示，姓名是可选的团队资料。
- 原团队现有五位成员保留原账号名登录，账户资料显示「元老账号」。这只是旧登录方式的兼容，不增加管理权限。
- `0029_account_identity` 在升级时固定原团队五个有效正式成员。新加入的成员、其他团队所有者和软件管理员不会自动获得这项兼容；新账号只使用工作台号登录，绑定邮箱用于找回密码；元老账号保留原邮箱登录兼容。
- 工作台号允许自定义一次。迁移保留原账户主键、密码、邮箱及业务关联，中文旧账号自动分配 `zy_` 工作台号。

## 导航、消息与团队

- 顶部「工作台」回到首页；我的团队、团队管理、团队广场属于工作台区域。
- 消息统一使用聊天、通讯录及内容三列布局，分别提供聊天、好友、新朋友、群聊和团队联系人。
- 点击头像可查看资料、添加好友或发消息。接受好友申请后资料卡更新为可私聊状态。
- 同团队成员可直接私聊，跨团队需要好友关系；团队权限独立授予。
- 个人聊天和群聊增加未读数与已读记录；既有团队聊天保留引用、红包、附件和表情功能。新增个人聊天和群聊当前仍以文字消息为主。
- 我的团队提供改名、管理和招募入口；团队可主动发布到团队广场。
- 左栏支持展开与收起，公告卡片增加留白，浅色模式保持白色侧栏。

## 浏览与更新

- 浏览器只出现在打开来源的区域，切换顶部导航或页面后关闭展示。
- 工具栏使用地址行和操作行，可展开、独立窗口、停靠、缩放及关闭。
- 可隐藏和恢复 AI 输入框，保留草稿。
- 软件更新公告进入独立「应用更新」页，与团队公告分开。
- 头像旁更新入口打开居中的大弹窗，显示功能、修复、安装包大小及下载进度。外部按钮持续显示下载圆环；下载和安装分别确认。

## 升级与检查

- 服务端迁移到 `core.0029_account_identity`，AI 迁移沿用 `aihub.0016`。
- 元老兼容仅在原团队恰好有五个有效正式成员时自动标记；其他安装不猜测账号、不自动给前五个新注册用户资格。
- 本地检查：539 项 Django、53 项 Node、5 项积分并发、13 套 Electron 界面检查，另有旧库迁移、元老登录迁移、团队准入及好友并发和本地认证检查。
- 本包来自未合并开发分支，未发布正式自动更新。Preview 暂未配置。服务器仍需管理员自行执行保留数据升级。
- 软件内部标识和数据目录沿用旧值，覆盖安装保留原连接配置和本地资料。

详细检查记录见 [本轮复查](REVIEW_0_2_20.md)。
