# 知域 0.4.0：个人自主与团队协作

## 用起来更清楚

- 工作台统一展示个人和团队的项目、比赛、实验，以归属标签区分；展开项目可直接查看任务和子任务。
- 聊天、通讯录、我的团队各有对应列表；团队内部使用概览、成员、申请、招募、邀请、设置分栏。
- 发现集中提供团队广场、人才市场、我的申请、合作邀请和人才资料。设置与软件管理使用自己的侧栏，返回恢复原位置。
- 个人概览显示待办与最近项目，不显示团队公告。应用更新采用独立弹窗。
- 群资料提供成员“＋ / −”；普通群支持多选，团队群通过正式资格与交接管理。
- 聊天与留言共用本地完整 emoji 面板：中文搜索、分类、最近使用、肤色、图片与 GIF 收藏。发送在右下角。
- 字段旁的笔进入编辑，Enter 或点击空白保存，Esc 取消。发送失败保留文字与附件，成员更新保留输入。
- 关于页分别显示客户端和服务端版本；关闭窗口隐藏到托盘。

## 合作与人才

人才资料默认不公开，由本人决定是否进入市场，也可屏蔽团队。团队选择公开招聘、仅定向邀请或暂停招募。主动申请审核通过后直接入队；定向 offer 需要本人接受，提供消息提醒、过期、拒绝、撤销。

可邀请人才加入团队，也可仅参与某个项目。项目合作不开放团队其他项目、实验库、财务或 API 池；项目负责人可结束合作并通知本人。学历与执照验证尚未接入。

## AI、隐私与经费

个人对话始终归本人。扣费来源单独选择个人或已授权团队，付款来源不会增加资料权限，也不会向团队公开提示词、回答或个人附件。助手可读取本人已有权限的多个项目，团队撤销资格后在下一次付费调用前再次检查。

个人可以先自行使用 API，再申请现金报销或团队 AI 额度补助。选择用量凭据只提交模型、时间与费用，不提交对话正文；同一用量避免重复报销。额度审核通过后入池；现金审批仅登记账目，不代表银行转账。

## 升级与数据

客户端和服务端均需使用 0.4.0。只覆盖客户端不能替换服务器提供的业务页面。

新增 core 0040–0044、aihub 0019–0020 迁移：人才与合作、扣费来源、用量凭据、个人历史归属和旧申请处理。旧 AI 历史迁回各自个人空间，保留原扣费来源及调用记录。旧的已通过申请按时间顺序处理，容量或资格不符时交回审核，不强行增加团队人数。

使用 `deploy/upgrade_preserve_data.sh --apply`：先对副本迁移，再备份并切换正式服务，保留原账号、业务数据、附件和 API 配置。**历史迁移不能直接反向执行；回滚必须恢复升级备份数据库，并配套恢复旧服务目录。**操作方法见交付包服务器升级说明。

Windows 安装包为 x64；本次没有提供新的 Mac 包。交付未自动覆盖本机客户端、服务器或公开更新渠道。

检查记录和参考来源见 [功能复查](REVIEW_0_4_0.md)。

## 文档与本轮修正

文档、修改授权、版本审核、成果引用与策划书计划已接入项目和任务。查看 `DOCUMENTS.md` 配置 Word、Excel 编辑服务。未配置时，文件仍可直接在应用内阅读。策划书生成会调用所选模型；先预览再确认，不自动补负责人、日期或预算。

“我的 API”合并连接与用量入口。普通成员可选择团队创建实验，管理团队实验仍需管理权限。消息切到仓库会丢弃旧网页回调并重算底部账号区；团队页面归入消息导航，软件管理员获得顶栏独立管理入口。
