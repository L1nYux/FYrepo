# 0.2.20 复查记录

本轮在 Windows 使用隔离数据库和隐藏桌面进程检查，不读取真实账户密码，不调用付费模型，不操作正式服务。

## 已检查

- 工作台首页、我的团队、团队管理、好友分类及引用页面的区域归属与返回。
- 展开与收起侧栏、桌面内容高度、浅色主题、成员资料和好友申请。
- 浏览器放大、独立窗口、导航后关闭展示，以及隐藏输入框后草稿保留。
- 应用更新大弹窗、安装包大小、外部进度圆环、取消与确认安装。
- 工作台号、昵称和姓名分离，元老兼容、新账号旧别名拒绝和工作台号冲突。
- 非元老账号的邮箱只用于找回密码，不能从网页或桌面登录入口绕过工作台号要求。
- 旧库升级固定五个原成员，新增管理员不获得兼容，密码与业务关联保留。
- 独立应用公告迁移、多个团队的业务权限和个人好友资料范围。
- Windows 安装包内容、更新摘要、大小和摘要校验。

## 检查范围

539 项 Django、53 项 Node、13 套 Electron 检查。另执行 5 项积分并发、原数据库迁移、元老登录迁移、团队准入并发、好友与所有权并发及本地桌面认证检查。

模拟网页和厂商响应检查控制流程及布局，不代表每个真实网站、代理或模型厂商均已验收。新增个人聊天和团队群目前以文字消息为主，媒体、红包等完整能力继续沿用既有团队聊天。

开发分支不触发正式发布；生产服务器升级与真实用户验收由管理员安排。
