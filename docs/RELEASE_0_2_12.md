# 科研工作台 0.2.12

## 搜索和引用

- 联网过程与最终回答分开；搜索到的网页和实际读取的页面分别计数。
- 正文引用编号定位真实来源，底部网页按钮打开右侧来源列表；阅读网页后返回保留列表位置。手机使用全屏来源抽屉。
- 过滤工具协议残片，流式回复、历史显示与后续对话一致；保留代码示例，不把工具调用阶段的临时文字当作最终回答。

## 应用更新

- 头像旁按钮先显示新版本功能、修复内容和当前系统安装包大小；确认后下载，圆环与百分比随时显示进度。
- 下载完成后单独确认安装，不在退出应用时偷偷安装。免费 Mac 校验下载后打开 DMG，仍需用户拖动覆盖。
- 服务端升级时发布本版公告，并安装每 15 分钟检查正式发布的任务；每个版本只发布一次。公告可打开同一更新入口，也可跳转相应功能；需要新版客户端或服务器时先提示更新。

## 用量

- 热力图按每日用量占周基础额度的比例，每 5% 加深一档，达到 25% 才显示最深色。
- 新用量记录保存当周基础额度供历史展示；旧记录缺少额度快照时明确标注估算，无上限额度不编造百分比。

## 检查和部署

- 387 项 Django、48 项 Node、5 项 SQLite 并发、10 套 Electron 界面检查；Linux 与 Windows 完整检查是正式发布前置条件。
- 使用独立数据和模拟厂商响应，没有付费模型调用或真实验证码邮件。Mac 双架构由 GitHub 构建，真实 Mac 安装仍需设备验收。
- core 迁移到 0022，aihub 到 0014。服务端须执行保留数据升级脚本；客户端升级不会自动迁移服务器。
