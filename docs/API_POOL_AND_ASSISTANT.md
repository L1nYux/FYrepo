# 公共 API 池与工作台助手

## 本地合并版本

基于 FYrepo `main` 的 `c9d518a`（2026-10-03 北京时间）：合入项目预算、财务按整本账本统计、共享报销、邮箱唯一性及邮件找回密码，同时保留本地桌面端、简化表单与附件工作流。本版本先本地查看，尚未上传或部署服务器。

## 管理员首次配置

1. 左下角头像 → 设置 → **API 池管理**。网页版从头像 → 账户设置 → API 池管理进入；工作台与助手不重复放置管理入口。管理页始终使用「连接与模型 / 额度与用量」两个标签，切换后保持设置导航。个人用量只从头像的「查看用量详情」进入。
2. 填写 **API 网址、API Key**，点击 **读取模型**。标准厂商自动识别，网址支持常用地址补全；连接名称和接口格式折叠在高级设置。打开已保存连接自动读取模型，Key 留空保留。相同基础网址和协议更新已有连接，不因名称大小写不同重复新建。
3. 勾选并保存接口实际返回的模型，支持搜索与全选。DeepSeek 在助手中按 **DeepSeek-V4.1-Flash / DeepSeek-V4-Pro** 选择，由同一个厂商连接提供。DeepSeek 与 OpenRouter 自动带入可读取的价格和汇率；无法取得价格的模型登记两项单价后才可调用。手工单价不自动覆盖。读取目录不发起模型推理，模型列表有 300 项与分页读取上限。
4. 进入 **额度与用量**，直接填写团队或成员周额度、保存、重置。月额度和其他限制折叠在可选设置；无需去另一个表单找重置按钮。

OpenAI 兼容基础地址通常包含 `/v1`，Anthropic 包含 `/v1`，Gemini 包含 `/v1beta`。输出上限参数可在高级选项中切换 `max_tokens` / `max_completion_tokens`。工具调用能力保留在高级设置，聊天的模型菜单只显示模型名称。

API Key 保存在数据目录的私有 `api-pool-keys.json`，也可使用环境变量。浏览器不会获取上游密钥；每位成员可选择实验并生成自己的 API Key，完整 Key 仅显示一次，数据库只保存其摘要。旧桌面个人连接密钥不自动导入、也不再用于助手请求。

## 成员使用

- 顶部 **AI 助手**：在输入框旁的单一模型菜单选择模型，按厂商分组，记住上次选择，直接提问；「＋ 引用」可选择项目、任务、实验、公告、消息、账目或报销。
- 项目、任务、实验详情中的「让助手整理」自动带入当前资料。
- 助手可查询本人待办、查找任务与实验、读取留言及可见成果、总结本人参与的私聊、提取附件文字，并返回来源链接。
- 助手只提供建议与草稿。没有发布、提交、审核、记账、删除、人事任免或执行代码工具。
- 默认最多三轮工具查询、一轮最终回答；每轮最多六个工具查询。可停止后续步骤，已发送给厂商的请求仍需结算。
- TXT、MD、CSV、JSON、源码、DOCX、XLSX、文本型 PDF 可提取正文；附件上限 5 MB，PDF 最多前 30 页。扫描件不做 OCR，旧版 DOC/XLS 与图片不提取正文。截断内容会提示。
- 读取权限由服务器按当前账户校验。私聊不跨参与者，也不因助手读取而标为已读。

## 用量与记账

公共 API 调用与助手走同一条服务端计量链路。每次调用记录成员、厂商、模型、输入/输出 token、缓存、推理 token、用途、价格版本、费用和状态。带入项目或实验时可关联费用归属。API 页面可以按厂商、模型、月份筛选；管理员可以看全体成员及成员汇总。

费用按调用开始时的价格版本和汇率结算；修改价格不会重算历史。推理 token 已包含在输出量中，不重复累计。调用前保守预留额度，返回用量后释放预留并扣除费用；超时、连接中断或缺少 usage 会保留额度并标为「费用待核对」。管理员对照供应商后台确认实际费用或确认未收费后结算，避免错误地把中断视作免费。

Token 单价估算与厂商最终账单可能不同。API 记录不自动生成每次调用的财务凭证；财务入账仍由管理员确认，避免碎片账目和重复统计。计量表不存提示词、回复正文或工具资料。AI 对话单独按账户保存，侧栏可搜索、切换、重命名或删除；删除不影响调用费用记录。本人对话历史不向其他成员或管理员开放。升级前的旧临时结果仍七天后清理。

## 每日价格

每日保存模型价格快照，变化时新增价格版本。DeepSeek 自动读取官方中文价目表，OpenRouter 自动读取其模型接口的单价；USD/CNY 使用 Frankfurter 发布的最近工作日参考汇率，来源和日期保存在价格版本中。参考汇率不是供应商账单汇率。

常用流程只需填网址、粘贴 Key、勾选模型。打开已有连接自动读取模型；可以搜索模型，列表显示价格读取状态，悬停可见单价。模型 ID、能力、输出参数无需逐项填写，Key 也无需重复输入。无法自动取得价格的厂商或自定义中转站，在「价格与高级模型设置」只补币种、输入与输出单价，缓存、汇率覆盖和其他参数放在可选/高级设置。

「自动读取价格」显式切换该模型到自动价格；「保存单价」切换为管理员登记，后续自动同步不会覆盖手工单价。自动来源失败或页面结构改变时保留最近有效价格；没有有效价格的模型保持不可调用，不推测价格为零。当前没有为 OpenAI、Anthropic、Gemini 实现官网价格解析，也不会使用其他平台的报价替代它们的实际单价。

可在模型高级选项指定运维维护的 HTTPS JSON 价格源，优先于内置来源。源更新失败时记录失败状态，继续采用最近有效版本。公开价格和汇率请求不携带团队 API Key。

价格源返回格式如下（示例字段，非真实报价）：

```json
{
  "model": "实际模型ID",
  "currency": "USD",
  "input_rate": "1.00",
  "output_rate": "5.00",
  "cached_rate": "0.10",
  "cache_write_rate": "1.25",
  "cny_exchange_rate": "7.00"
}
```

本地桌面开启时每 15 分钟检查一次，当天已有快照则跳过。Linux 部署提供 `deploy/install-api-prices.sh`，安装每日北京时间 00:15 的 systemd timer，并在开机后补查。可手动执行 `python manage.py refresh_api_prices` 或在管理页立即更新。

## 从脚本或其他软件调用

在头像 → 查看用量详情中打开「我的 API Key」，先选关联实验，再生成个人 Key。可以复制地址、Key、模型 ID 和 Python/curl 调用示例。基础地址为工作台地址加 `/api/pool/v1`。新 Key 的调用自动归属所选实验；旧 Key 每次请求必须填写 `experiment_id`。

- `GET /api/pool/v1/models` 返回已配置模型；使用返回的 `id`（厂商编号/模型ID），避免厂商之间重名。
- `GET /api/pool/v1/experiments` 返回可关联的实验，支持 `q` 搜索；每页最多 200 条，并返回 `has_more`。
- `POST /api/pool/v1/chat/completions` 提供非流式文本 Chat Completions 入口。独立调用必须关联实验；新 Key 自动绑定，提供 `experiment_id` 时须与 Key 一致。
- 支持 `model`、`messages`、`stream=false`、`temperature`、`top_p`、`stop`、`max_tokens` 或 `max_completion_tokens`、函数 `tools`；可选 `project_id`；新 Key 可省略 `experiment_id`，旧 Key 必须提供。
- 暂未实现流式、图片输入、Responses、语音或完整 Claude/Gemini 客户端端点。输出上限与参数还须符合所选厂商的限制。不支持的请求参数会报错，不静默忽略实验条件。
- 此接口只转发工具定义与回复，不执行调用者自定义的工具；工作台内置助手才执行四种只读工具。

## 本地 DeepSeek 与代理

在左下角头像 → 设置 → API 池管理配置。DeepSeek 使用 `https://api.deepseek.com`，模型列表由官方 `/models` 获取。使用非思考模式完成资料查询。无需在聊天或源码中填入密钥；读取目录不发送聊天或发起推理。

Key 保存在本地数据目录的 `api-pool-keys.json`，不返回给浏览器，也不要打包进 GitHub。Key 不会自动同步到服务器；以后部署由管理员在服务端另行配置。重复打开配置时不会显示已有 Key，留空保留原值。

DeepSeek 的 Flash 与 Pro 单价由官方中文价目表读取，不再使用固定写死的参考报价。当前按官方高峰价保守估算，暂未按时段和法定节假日动态切价，低峰实际费用可能更低。价格来源会明确标注这一点；实际扣费以厂商账单为准。历史调用仍使用发起调用时的价格版本。

每轮助手先读取当前账户的项目、待办与最新公告，再按问题通过工具查找详情、留言、成果及附件。读取过程与来源会显示在回答中，私聊沿用当前账户权限。助手目前只读取并给出建议或草稿，发送的内容与读取到的相关资料会交由所选厂商处理。

本地桌面版兼容代理 Fake-IP 的 `198.18.0.0/15` 地址段，服务器仍保持非公网地址拦截，本地也不会整体放开其他内网地址。已使用保存的 DeepSeek Key 读取官方目录，实际返回 `deepseek-flash` 与 `deepseek-v4-pro`；未发起模型推理或扣除工作台额度。

## 可视化用量、周额度与重置

左下角头像菜单显示个人本周、本月剩余额度比例与自动恢复时间。点击「查看用量详情」查看近 7 天的估算费用、Token 数及按模型分布。管理员可切换「团队用量」，查看每位成员本周实际用量、周/月额度进度，并重置指定成员或团队的当前周/月额度。

API 池 → 额度与用量：填写团队每周上限、成员默认周额度，并为具体成员设置周额度和月额度。周额度留空不额外限制，填写 0 表示零元额度。默认周额度只影响之后首次建立额度配置的成员，现有成员逐个调整；月额度保留原值。每周按北京时间周一 00:00 开始，每月按一日 00:00 开始。周、月、个人、团队限制同时校验；脚本调用与 AI 助手共用限制。

「重置额度」默认恢复当前周及当前月的工作台额度，历史调用和费用仍保留；执行中或待核对的预留不释放，待返回后正常结算。重置成员不重置团队，重置团队也不重置成员。重置不会增加厂商账户余额或撤销已经发生的费用。图表反映历史实际记录，不因额度重置归零。

桌面和网页登录增加「保持登录（30天）」；桌面默认勾选，只保存登录会话，不保存明文账户密码。主动退出、密码修改、会话到期或管理员停用仍需重新登录。API Key、启用模型和额度配置保存在原数据目录；助手上次选择的模型保存到个人账户，在重启、随机端口变化或换端后也能恢复。

数据库升级 `aihub.0002_weekly_allowances` 为历史调用回填所属周，建立周用量汇总，不修改原调用费用或账户。首次周额度保持不限制，管理员自行设置；本次实现没有替你点击重置、没有产生示例用量或付费模型调用。

## 桌面右键菜单

桌面窗口、工作台内嵌页面和头像区统一提供系统菜单：剪切、复制、粘贴、全选。聊天输入框、API Key 表单、本地文件编辑器均可使用；无法操作的菜单项按当前编辑状态置灰，密码框沿用系统复制限制。网页版使用浏览器原生右键菜单。

## Token 活动图

头像 → 查看用量详情，可以查看个人最近 365 天的活动格子；管理员团队视图统计全体成员。每天按日期统计输入加输出 Token，每周聚合为周用量，累计总量显示从这 365 天区间起点至对应日期的累计，不是账户全历史总量。悬停、键盘聚焦或点击显示日期、Token、调用次数及估算费用。颜色随用量增加，空日期不填示例值；重置额度不会抹掉活动格子。

当前本地库中的重复 DeepSeek 空连接只停用并从常用页面隐藏，保留原私有配置；有模型和历史调用的连接继续使用。Flash 与 Pro 仍通过官方目录读取，不自行猜测不可用的模型。

## API 池负责人权限

`aihub.0003_pool_owner` 增加唯一池负责人。已有且只有一名有效管理员时自动绑定该账号；多人管理员环境不猜测归属。可在迁移前设置 `WORKBENCH_API_OWNER_USERNAME`，或通过服务器执行 `python manage.py set_api_owner 用户名`。新建本地预览时，首次设置的管理员成为池负责人。其他管理员仍保留项目、人事和财务权限，但不能自动管理 API 池。

所有池配置、价格修改、团队用量、额度修改与重置均检查负责人身份。成员的页面、助手模型目录和用量接口只返回个人用量；不返回团队额度、其他成员、价格历史或私有连接配置。成员仍可选模型并生成个人脚本调用凭证。AI 助手与外部调用共用原有计量和额度校验。

## 外观与紧凑界面

桌面左下角头像 → 设置 → 外观：深色、浅色、跟随系统，选择 PNG/JPG/WebP 本地壁纸（10 MB 内），调节透明度和模糊，或恢复默认。设置即时保存到本机的 `appearance.json`，壁纸复制为本地 `wallpaper-image`；它们不进入服务器数据库或源码仓库。窗口、账户菜单、工作台与编辑器使用一致的主题；表单、正文卡片和代码编辑区域保留清晰的底色。网页版主题按钮循环深色、浅色、跟随系统，保存于浏览器本地。

按钮与表单行高、卡片留白和圆角收紧。桌面右键改为紧凑应用菜单，四项编辑功能依当前输入状态启用，显示快捷键，支持 Esc 关闭。Token 活动由浅橙递增为深橙，用量越多颜色越深；没有改动历史调用或额度。
