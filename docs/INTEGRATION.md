## 本轮新增与优化

- **桌面版**：Electron 窗口、团队 logo、桌面 / 开始菜单快捷方式；统一顶部区域切换、左下角账户菜单，退出登录回登录界面；设置与业务入口分开。访客展示页保持独立。
- **减轻填写负担**：项目 / 任务 / 比赛先填名称，其余折叠为可选项；任务成果支持一句话或附件；实验支持通用文字 / 文件记录；恢复与彻底删除集中在回收站。
- **消息**：公共讨论、私聊、业务引用、在线 / 未读状态；右键复制、撤回本人消息、从本人记录删除；撤回后在聊天背景显示轻提示，可重新编辑，不设倒计时；附件与引用仍按原权限检查。
- **公共 API 池**：负责人填写接口网址与 Key 后读取模型目录，支持多厂商；已支持的价格来源自动读取、每日快照、历史单价；其他来源需手动确认价格。只有池负责人可配置连接、模型和额度，成员查看自己的用量。
- **额度和费用**：成员 / 团队周月额度、重置、实际 Token / 费用图表；助手和脚本中转共用计量；重置保留历史费用及未完成调用预留。
- **AI 助手**：只读查询本人有权查看的任务、项目、公告、实验、聊天和附件，显示来源与读取过程；独立对话侧栏支持新建、标题搜索、切换、重命名、删除及历史保存。其他成员和管理员不能通过对话接口读取某个成员的个人 AI 历史。
- **本地能力**：Git 文件工作区、同步、系统剪切复制粘贴菜单、深浅色及本地壁纸；Git 同步需要成员自己的 Git 认证。
- **调试修复**：恢复邮箱唯一索引、修复账户 / 安全设置页签定位、助手重复提交与失效请求重试、额度异常输入及重复导航。

本次交付为独立审阅分支，不自动合并或部署。

## 运维先看

1. **保留线上数据**：备份服务器数据库、附件、环境配置和旧代码，再更新源码、安装依赖、执行 `migrate` / `collectstatic`、重启服务。不能用本地预览数据库覆盖线上数据库，也不能因迁移冲突盲目使用 `--fake`。
2. **API 配置在环境中独立管理**：源码不含 API Key、成员凭证、数据库或私有附件。升级不会替团队配置真实厂商连接或 SMTP；池负责人需在目标环境确认所有权、配置连接并启用模型。
3. **桌面 0.2.2 的团队服务器连接**：已加入服务器会话认证、持久连接设置、安装包配置、自动检查 / 下载更新。正常启动均自动连接预设团队服务器，无模式选择和首次网址填写；独立测试服务只在开发命令 npm run dev:local 下启动。正式下载和自动更新依赖 GitHub 发布；macOS 正式更新需要 Apple 签名。2026-10-04 线上服务器已完成保留数据升级，公网桌面状态接口返回 protocol=1；成员真实账户登录仍需确认。详见 [上线交接](CONNECT_AND_RELEASE.md)。
4. **助手目前只读取和起草**：不自动发布任务、审核、记账或执行本机命令。发送内容及选取的工作资料会交给所选模型厂商；接入前按团队要求配置厂商。

功能细节见 [使用说明书](USER_GUIDE.md)，运维命令见 [运维说明](MAINTENANCE.md)。

## 只导入旧账号

不兼容旧库且只需保留账号时，在新空数据库迁移完成后使用：

```bash
python manage.py import_accounts --source /path/to/old.sqlite3
```

导入保留账号 ID、密码摘要、姓名、邮箱、启停及管理员状态，以及可映射的组权限；不显示或重置密码，不导入旧会话和旧业务数据。用户需要重新登录。目标已有用户或自定义权限无法映射时会停止，避免覆盖。

默认安装可使用独立新发布目录中的脚本：

```bash
sudo bash /path/to/new-release/deploy/upgrade_accounts_only.sh --apply-accounts-only
```

脚本适用于 `/opt/research-workbench`、`/var/lib/research-workbench` 与既有 systemd 服务；准备新库、停服务、导入账号、保留旧代码和数据、切换新版，并在失败时尝试恢复旧服务。此操作不保留旧业务记录到新版，须由运维明确选择。
