## 只导入旧账号

不兼容旧库且只需保留账号时，在新空数据库迁移完成后使用：

```bash
python manage.py import_accounts --source /path/to/old.sqlite3
```

导入保留账号 ID、密码摘要、姓名、邮箱、启停及管理员状态，以及可映射的组权限；不显示或重置密码，不导入旧会话和旧业务数据。用户需要重新登录。目标已有用户或自定义权限无法映射时会停止，避免覆盖。

默认安装可使用独立新发布目录中的脚本：

```bash
sudo bash /path/to/new-release/deploy/upgrade_accounts_only.sh --apply-accounts-only
```

脚本适用于 `/opt/research-workbench`、`/var/lib/research-workbench` 与既有 systemd 服务；准备新库、停服务、导入账号、保留旧代码和数据、切换新版，并在失败时尝试恢复旧服务。此操作不保留旧业务记录到新版，须由运维明确选择。

本地预览已经应用 `0006`、`0007`、`0008`、`0009`、`0010`，迁移前保存了数据库副本。仓库自带自动化测试（`manage.py test core`，175 个用例全部通过），但当前发布仍未部署生产环境；自动化测试通过不能替代团队在预览环境对比赛、私聊、引用、报销与账目项目归属、项目成本汇总及邮箱自助找回的功能验收。
