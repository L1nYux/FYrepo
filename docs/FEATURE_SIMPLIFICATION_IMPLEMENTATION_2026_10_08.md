# 功能精简实施记录

日期：2026-10-08。基于用户确认的 [审查方案](FEATURE_SIMPLIFICATION_REVIEW_2026_10_08.md)。本轮作为 0.4.2 交付；服务器由运维使用交付命令升级。

## 已修改

1. 个人记账：撤下“我”及桌面导航入口；旧记账链接跳回个人主页。个人新增、编辑、作废和归档入口停止写入，团队财务功能与原有数据保留。
2. 个人 API 池：旧“我的 API”页面改为兼容跳转；厂商管理与扣费来源只允许团队。普通成员自己的调用 Key 仍可管理，不能进入厂商密钥配置。
3. API 调用：集中在 AI 模块，地址、Key、模型、额度和用量在同一页面。Key 面板默认展开，放在用量图表前；不再以实验存在作为基本调用前提。
4. 可选归属：团队 Key 可以不绑定项目或实验；也可以绑定项目或实验。服务端校验访问权限、团队归属、项目与实验关系；已有实验绑定继续生效。项目绑定 Key 只能关联该项目中的实验。
5. 助手：额度来源只列获授权团队，对话历史继续归本人。无团队或无可用 API 授权时提供团队引导。桌面关闭助手对话模块后，AI 入口仍能进入 API 调用页。
6. 导航：API 管理从个人设置移到 AI 模块。软件管理只保留平台账号、团队容量及操作记录，删除重复正文按钮及设置中的平台跳转。账户页清除标题和页头中误写的重复卡片。
7. 团队管理：工作台提供统一入口；“消息”侧栏保留聊天与通讯录。旧 `/teams/` 链接兼容跳转，团队管理使用工作台的团队选择上下文。团队页提供切换团队、创建与邀请码加入入口。
8. 招聘：新增计划人数，按该招聘的正式入队记录计算；达到计划后关闭。审核入队与旧招聘邀请码入队均检查计划人数，团队硬性容量仍通过统一 admission 流程检查。
9. 桌面权限：远程与本地预览状态接口修正 API 管理权限及无团队判断；额度弹窗使用团队 API 空间，不再误查个人池。
10. 指南：同步当前入口及额度说明。积分红包、人才市场、人才资料公开开关、HR 权限规则保留。

## 数据与升级

- 新迁移：`aihub.0021_membertoken_optional_project`、`core.0046_opening_planned_headcount`。
- 没有删除个人空间、财务数据、API 凭据或历史消费记录。停用个人池不会把其数据或额度自动转给团队。
- 历史招聘计划人数未知，迁移保留为空。HR 可在招募页补设；补设前该招聘不能继续完成入队，不能替用户猜人数。
- 同步升级服务端和客户端后才能体验完整入口调整。本轮客户端与服务端版本同步为 0.4.2。
