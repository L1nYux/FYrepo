# 知域 0.3.1：入口、聊天与通知

## 本轮改动

- 项目、比赛、实验统一列出个人和已加入团队的内容，显示归属标签，可筛选。侧栏条目放在对应栏目下。
- 打开资料自动检查所属空间及权限；创建时选择归属。个人数据与各团队数据继续独立保存。
- 概览汇总自己的待办、最近项目和团队公告。团队列表负责发现与进入，成员管理留在消息区域。
- 财务、API 池、AI 对话显示并保留当前归属；从项目或任务进入助手沿用资料归属。
- 群资料只保留一个入口。点笔编辑，Enter 或点击空白保存，Esc 取消；失败保留输入。各字段独立保存。
- 群成员搜索、个人备注、群昵称、置顶、免打扰和昵称显示使用同一资料面板。
- 审核通过后申请人收到系统通知；确认加入或取消加入后审核人收到通知。升级时给已有待确认申请补发提醒。
- 验证邮箱即可注册，团队邀请码可选。每个个人账号都有自己的空间。
- 默认表情为 Unicode emoji。聊天与留言支持自有图片和 GIF；留言允许只发图片。
- 应用更新使用独立弹窗。桌面窗口关闭时隐藏到托盘，托盘菜单恢复或退出；账户菜单的退出实际结束程序。
- 团队授权增加常用职位模板，选择后仍由管理人保存。

## 使用新版本

服务端需要使用本轮源码并执行 `core.0039_navigation_notifications_preferences` 迁移；该迁移增加系统通知和群偏好，不删除原业务数据。

桌面客户端覆盖安装 0.3.1。仅安装客户端不会更新服务器提供的页面。服务端升级方法继续使用 `deploy/upgrade_preserve_data.sh`；先准备与备份，再应用。

本轮交付未自动替换正在运行的服务端或已安装客户端，也未合并分支或创建正式发布。
