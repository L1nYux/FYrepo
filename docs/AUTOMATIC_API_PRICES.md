# 自动读取模型价格

2026-10-04 补充百炼、智谱 GLM、MiniMax 的官方价格来源。此次仅更新服务器网页与接口，桌面客户端无需重装，没有新增数据库迁移。

## 已接入来源

| 连接 | 自动来源 | 范围 |
| --- | --- | --- |
| 百炼 `dashscope.aliyuncs.com` | 官方公开价格页 | 北京地域、中国内地部署；该渠道上的模型均使用百炼价 |
| 百炼北京业务空间域名 | 官方 `GET /api/v1/models`，失败时回退到公开价格页 | 显式使用中国内地部署筛选；回退来源会显示在价格记录中 |
| 智谱 `open.bigmodel.cn` | 官方定价文档的 Markdown 表格 | 智谱直连文本、视觉对话模型的按量价格 |
| MiniMax 国内官方域名 | 官方国内按量定价文档 | CNY 标准服务输入、输出、缓存读取与文档明确提供的缓存写入价 |
| MiniMax 国际官方域名 | 官方国际按量定价文档 | USD 单价与人民币汇率 |
| DeepSeek、OpenRouter | 原有官方价格来源 | 保留原有接入 |

百炼的其他地域、全球部署、Coding Plan 专用地址以及自定义转发连接暂不自动套用国内直连价格。未接入的连接会显示说明并禁用自动读取按钮，仍可手动登记价格。

## 估算口径

- 页面保留每百万 Token 的单价单位；不会把每千 Token、每次、每张或每小时费用写入 Token 单价。
- 工作台目前按固定单价估算预算。长度阶梯或模式价格不同的模型使用各计费项的最高档，来源记录明确标注「最高档保守估算」。短上下文实际费用可能低于工作台估算。
- MiniMax 采用标准服务价格，优先服务价格不混入；明确的划线优惠价格使用当前折后价。
- 智谱读取文档明确列出的缓存命中价；不支持缓存时沿用普通输入单价。百炼缓存价格暂按普通输入估算，并在来源中标注。
- 缓存按时长存储、服务端工具等额外计费项不包括在两项 Token 单价中；本功能不代表完整账单对账。
- 厂商赠送额度与订阅套餐不把模型单价变成零。M Plan、Token Plan、Coding Plan 的实际消耗以厂商额度和账单为准；工作台成员点数继续使用配置的参考单价。
- 公开价格缓存一小时。逐模型点击自动读取会重新核对；批量同步使用缓存且保留管理员手填价格。读取价格不会调用模型推理。

## 失败与密钥处理

- 网络错误、汇率错误、页面结构变化、无法识别的型号或计费单位均保留旧价格；未定价模型保持待补，不默认为免费。
- 自动读取按钮失败后可重试；保存成功立即更新价格状态筛选和待补数量。
- Key 不发送给公开文档站。只有显式配置的百炼北京官方业务空间域名会收到认证请求；缓存标识使用哈希，界面不返回 Key。
- 打开管理页面不会等待价格网络请求。只有读取目录、逐模型读取或同步价格时才访问价格源。

## 验证

- 255 项 Django 测试通过，其中新增 21 项价格来源、币种、阶梯、优惠、缓存、权限、密钥边界与失败保留检查。
- 25 项桌面逻辑测试通过；实际 Electron 价格界面 15 项、模型目录 15 项、原有助手与额度界面 11 项通过。
- 已下载官方公开页面核对解析结果：百炼 213 个可识别 Token 定价型号、智谱 32 个、MiniMax 国内 8 个。这个数量随官方文档变化，不表示当前账户可调用所有型号。
- 界面与认证接口测试使用模拟数据，未使用真实 Key 发起模型推理或测试厂商账户。
