准备采集器

下载采集器 ZIP

下载包已包含启动文件、采集引擎及固定版本安装组件；完整解压后即可开始配置。

  1. 完整解压到电脑

    在解压后的 FYrepo-CNKI-Agent 文件夹中保留 tools 和 vendor，不要只取出 CMD 文件。

  2. 启动采集器

    Windows 双击 START_CNKI_AGENT_WINDOWS.cmd。需要 Python 3.11+；已安装 Python Launcher 或 Anaconda 时会自动寻找。首次运行会建立独立环境、安装依赖，请保持窗口打开。

    macOS / Linux 在该文件夹运行 bash START_CNKI_AGENT_MAC_LINUX.sh。

  3. 粘贴连接码

    回到“样本库 → 样本集 → 知网采集”，粘贴启动窗口显示的连接码并点击“检查连接”。浏览器询问本地网络访问权限时允许当前工作台访问。

  4. 完成本人知网登录

    依次点击“安装 / 修复采集组件 → 打开知网登录”。在本机浏览器完成机构认证、安全验证，再点击“登录完成 → 开始采集”。
